# Amended Returns (Form 760 header, Amended Return oval and reason code)
## Description
Virginia amends on the same Form 760: fill in the Amended Return oval, enter a reason code, and complete a new return with the corrected figures as if it were the original. Anyone who amends a federal return must also amend the Virginia return and pay any additional tax and interest. Federal adjustments must be reported, and any additional amount paid, within one year after the final determination date.
## Reason codes
| Code | Reason |
|---|---|
| 01 | NOL |
| 02 | Partnership Level Federal Adjustment - enclose Form 502FED-1 |
| 03 | Federal Return Amended or Adjusted - enclose copy of IRS final determination, if applicable |
| 04 | Virginia Return - changes to subtractions, deductions, additions, and credits |
| 05 | Pass-Through Entity Elective Tax Payment Credit |
| 30 | Other - enclose explanation |
## Final determination date (one-year requirement)
- IRS audit or other action: the first day on which no federal adjustments from that action remain to be finally determined; for agreements signed by the IRS and taxpayer, the date the last party signed. For a member of a Virginia combined or consolidated return, when nothing remains open for the entire group.
- Amended federal return, refund claim or administrative adjustment request: the day it was filed.
- If the IRS acknowledged acceptance of the federal amended return, enclose a copy.
- An amended return filed with another state that affects Virginia tax requires an amended Virginia return within one year.
## Refund time limits
A refund is allowed only if the amended return is filed within: 3 years from the original due date including valid extensions; 1 year from the final determination of a federal change (refund limited to the Virginia decrease from that change); 1 year from another state's final change (same limit); 2 years from filing an amended Virginia return that paid additional tax (issues relating only to that return, refund limited to that payment); or 2 years from paying an assessment (issues relating only to it, refund limited to the tax paid).
## Worksheet for Amended Returns
1. Tax paid with the original return plus tax paid after it was filed
2. Line 1 plus Line 26 of the amended Form 760
3. Overpayment shown on the original return or as previously adjusted
4. Line 2 minus Line 3
5. If Line 4 is less than amended Line 18: Line 18 minus Line 4 = tax you owe
6. If amended Line 18 is less than Line 4: Line 4 minus Line 18 = refund
Do not adjust the amended return itself for refunds received or balances paid on the original. Additional tax due carries interest from the original due date to the date the amended return is filed or postmarked.
## NOL carryback
Use the NOL instructions in the Virginia Administrative Code, 23VAC10-110-80 and 23VAC10-110-81, and enclose a complete copy of the amended federal return and the Virginia Modification Worksheet, if applicable.
## Questions
- Did you amend your federal return or receive an IRS adjustment? When was it final?
- Did a partnership send you Form 502FED-1?
- Did you amend a return with another state?
- What was paid or refunded on the original Virginia return?
## Common Errors
- Missing the one-year deadline after a federal final determination
- Netting the original refund or payment into the amended Form 760 figures instead of using the worksheet
- Omitting the reason code or the required enclosure (502FED-1, IRS determination, explanation)
- Forgetting interest on additional tax from the original due date
