# Income from Virginia Obligations (Schedule ADJ, Lines 6b-6d, code 20)
## Description
Virginia does not tax income from its own state and municipal obligations. If any such income is included in federal adjusted gross income, for example interest on Virginia bonds that is federally taxable, or gain from selling Virginia obligations, it is subtracted using subtraction code 20.
## What to enter
- Income from Virginia obligations included in federal AGI
- Includes interest on Virginia state bonds or municipal obligations and gains from sales of those obligations that are included in federal AGI
- Enter code 20 in a code box on Line 6b, 6c or 6d, followed by the amount
## Code 20 appears twice
Subtraction code 20 (this item) is not addition code 20, the Pass-Through Entity Tax Add Back entered on Lines 2b-2c.
## Questions
- Do you own Virginia state or local government bonds?
- Is any of that interest taxable on your federal return, or did you sell any at a gain?
## Common Errors
- Subtracting federally tax-exempt Virginia bond interest that was never in federal AGI
- Confusing this code with addition code 20
## Prompt
- I sold some Virginia municipal bonds at a gain.
