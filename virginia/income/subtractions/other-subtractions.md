# Other Subtractions (Schedule ADJ, Lines 6b-6d, code 99)
## Description
Code 99 is the catch-all subtraction for any income included in federal adjusted gross income that is not taxable in Virginia and is not covered by Form 760, Lines 4-6, Schedule ADJ, Lines 4-6a, or another subtraction code.
## What to enter
- The amount of any other subtraction included in federal AGI which is not taxable in Virginia
- Enter code 99 on Line 6b, 6c or 6d, followed by the amount
## Explanation required
- Paper filers: enclose an explanation and supporting documentation, if applicable
- Electronic filers: provide a detailed explanation in the space provided by the software program
## General limits
No amount previously excluded from FAGI can be subtracted, and the same income may not be included in more than one subtraction.
## Questions
- Do you have income on your federal return that Virginia law exempts and that does not fit one of the listed subtraction codes?
## Common Errors
- Using code 99 for an item that has its own code or line
- Omitting the explanation
## Prompt
- I have income that I believe Virginia exempts but I can't find a code for it.
