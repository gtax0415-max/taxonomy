# Federal Partnership Income Addition (Schedule ADJ, Lines 2b-2c, code 19)
## Description
When a federal partnership audit increases a partner's income, Virginia requires the owner to report that income on their Virginia return if it was not previously reported on the original Virginia return. The addition uses code 19. The opposite case, income previously reported that should not have been, is subtraction code 59.
## What to enter
- The income related to a federal partnership audit that was not previously reported on the original Virginia return
- The amount equals the income that was not included in Virginia taxable income
- Enter code 19 on Line 2b or 2c, followed by the amount
## What to enclose
The partnership's completed Form 502FED-1.
## Questions
- Is a partnership you own an interest in subject to a federal (IRS) partnership audit?
- Did you receive a Form 502FED-1 from the partnership?
- Was the adjusted income left out of your original Virginia return?
## Common Errors
- Reporting the adjustment without enclosing Form 502FED-1
- Adding income that was already included on the original Virginia return
- Using code 19 when the audit reduced income (that is subtraction code 59)
## Prompt
- The IRS audited my partnership and I got a Virginia Form 502FED-1.
