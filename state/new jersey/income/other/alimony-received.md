# Alimony and Separate Maintenance Payments Received
## Description
Court-ordered alimony and separate maintenance received is TAXABLE in New Jersey — including under divorces finalized after 2018, for which it is NOT taxable federally.
## Notes
- Child support is not income
- NJ did not adopt the 2018 federal change (TCJA) that ended alimony inclusion/deduction for new divorces
- The paying spouse deducts it on Line 32 — see new-jersey/deductions/personal/alimony-paid.md
- Part-year residents: include only payments received while a resident
## Questions
- Do you receive court-ordered alimony or separate maintenance?
- Is any part of the payment child support?
## Common Errors
- Leaving alimony off the NJ return because it is not taxable federally
- Including child support
## Prompt
- I get alimony from my ex. My divorce was in 2021. Is it taxable in New Jersey?
