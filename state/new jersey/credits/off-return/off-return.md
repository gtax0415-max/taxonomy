# Credits Claimed Off the Return
## Description
Certificate-based business and incentive credits that CANNOT be entered on Form NJ-1040, NJ-1040NR, or NJ-1041. The taxpayer files the return first, then mails a separate claim.
## Credits in this folder
- Neighborhood Revitalization State Tax Credit (neighborhood-revitalization-credit.md) — Form GIT-311
- Film and Digital Media Tax Credit (film-digital-media-credit.md) — Form GIT-327
- Apprenticeship Program Tax Credit (apprenticeship-program-credit.md) — Form GIT-330
- Low Embodied Carbon Concrete Tax Credit (low-embodied-carbon-concrete-credit.md) — Form GIT-337
## How to claim (all four)
1. File the NJ income tax return first
2. Mail the completed GIT form with: a cover letter (name, daytime phone, mailing address), a copy of the NJ return, and a copy of the certificate or approval letter
3. Send to: New Jersey Division of Taxation, Grant & Credit Review Unit, PO Box 272, Trenton, NJ 08695-0272
## Ordering
The GIT-327, GIT-330, and GIT-337 computations subtract "other credits not shown on the NJ-1040" (e.g., Angel Investor Tax Credit), so when several off-return credits are claimed, list each on the others' forms.
