# Donation and Contribution Credits (Georgia)
## Description
Credits for preapproved donations to specific organizations. These are Series 100 credits claimed on Form 500, Schedule 2 (Line 21) — but individuals routinely claim them, so they belong in the individual taxonomy. Two rules run through all of them: preapproval through the Georgia Tax Center is required BEFORE donating, and you enter YOUR SSN on Schedule 2, not the recipient organization's FEIN. Any return claiming a Series 100 credit must be filed electronically. The "Add Back" pool functionality for donation credits begins in tax year 2026.
## Credits in this folder
- Qualified Education Expense Credit — QEE (qualified-education-expense-credit.md) — Schedule 2 → Line 21. Student Scholarship Organization donations. Code 125
- Qualified Rural Hospital Organization Expense Credit — RHO (qualified-rural-hospital-organization-credit.md) — Schedule 2 → Line 21. Rural hospital donations. Code 136
- Qualified Education Donation Credit — QED / PEACH (qualified-education-donation-credit.md) — Schedule 2 → Line 21. Public education donations (TY2018+). Code 140
- Qualified Law Enforcement Donation Credit — QLED (qualified-law-enforcement-donation-credit.md) — Schedule 2 → Line 21. Local law enforcement foundation donations (TY2023–2027). Code 150
- Qualified Foster Child Donation Credit — QFCD (qualified-foster-child-donation-credit.md) — Schedule 2 → Line 21. Foster child support organization donations (TY2023+). Code 151
## Five donation credits, one set of rules
| Credit | Recipient | Code |
|---|---|---|
| QEE | Student Scholarship Organization | 125 |
| RHO | Rural Hospital Organization | 136 |
| QED / PEACH | Public education | 140 |
| QLED | Local law enforcement foundation | 150 |
| QFCD | Foster child support organization | 151 |
All are first-come, first-served against annual statewide caps, preapproved through GTC, and require entering your SSN (not the organization FEIN) on Schedule 2.
