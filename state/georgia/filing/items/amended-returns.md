# Amended Returns (Georgia)
## Description
Corrections to a previously filed Georgia return are made on Form 500X, not by refiling Form 500. Form 500X can also serve as an original return in some cases.
## When to file Form 500X
- To correct a previously filed Form 500 (do NOT use Form 500 to correct a prior return)
- When federal changes (an amended federal return or IRS final determination) affect Georgia
- The "final determination date" is the date the amended return, claim, adjustment request, or related report is filed
## Refund claim window
A refund resulting from an amended return must be claimed within three years from the later of the date the tax was paid or the return due date (including extensions). Changes flowing from a federal adjustment have their own timing tied to the final determination date.
## Required Information
- The original Georgia return being corrected
- Original or amended federal return and any IRS final determination
- Supporting schedules for the changed items
## Questions
- Do you need to correct a Georgia return you already filed?
- Did your federal return change (amendment or IRS adjustment)?
- Is your correction within the refund claim window?
## Common Errors
- Using Form 500 instead of Form 500X to amend
- Missing the three-year refund window on an amended claim
- Not reporting federal changes that affect Georgia
