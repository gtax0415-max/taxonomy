# Filing Status, Residency, and Return Mechanics (Georgia)
## Description
The structural attributes that frame the whole return: who must file, filing status, residency type (which decides whether you use the Form 500 main lines or Schedule 3), extensions, and amended returns. These aren't dollar items on a single line — they determine which computation path the rest of the taxonomy follows.

- Amended Returns (items/amended-returns.md) — Form 500X
## The core split: main form vs Schedule 3
- FULL-YEAR residents use Form 500 Lines 9–14 directly
- PART-YEAR residents and NONRESIDENTS SKIP Lines 9–14 and complete Schedule 3 to compute Georgia taxable income by proration
Nearly every income, deduction, and exclusion item in this taxonomy has a "part-year/nonresident must prorate" note that ties back to this split.
