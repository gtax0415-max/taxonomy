# Tax Computation (Georgia)
## Description
After Georgia taxable income is set on Line 15c, the tax itself is computed by applying Georgia's flat rate (Line 16), then reduced by total credits used (Line 22) to a balance (Line 23). Georgia switched from graduated brackets to a single flat rate in 2024 and has cut that rate every year since.
## The flow
- Line 15c = Georgia taxable income
- Line 16 = Line 15c × the flat rate, rounded to the nearest dollar
- Lines 17–21 = credits (Low Income, Other State, Eligible Itemizer, IND-CR Summary, Schedule 2) — see credits/ branch
- Line 22 = total credits used (sum of Lines 17–21); cannot exceed Line 16
- Line 23 = balance (Line 16 minus Line 22); if zero or negative, enter zero

## 2026 rate (HB 463)
The flat rate for tax year 2026 is 4.99% (down from 5.19% for 2025). Note the 2025 IT-511 booklet prints 5.19% on the Line 16 instruction; for a 2026 return use 4.99%.
