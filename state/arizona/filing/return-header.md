# Return Header (Form 140, Page 1: Box 82F, Fiscal Year, Lines 1 to 3, Boxes 94 and 97)
## Description
The page 1 header identifies the taxpayer and the return period. None of these entries changes the tax, but missing or wrong SSNs delay processing and can bring a penalty.
## Header entries
| Item | Entry |
|---|---|
| Box 82F | Check if filing under an extension (Arizona Form 204 or federal Form 4868) |
| 66F (fiscal year) | Calendar year filers leave blank; fiscal year filers enter the beginning and ending month, day and year |
| Line 1 | Your first name, middle initial, last name and SSN; on the second line 1 the spouse's name and SSN (if box 4 or 6 is checked) |
| Line 2 | Current home address, number and street or rural route, apartment number; box 94 daytime phone with area code |
| Line 3 | City, town or post office, state and ZIP code; box 97 last names used in the last four prior years, if different |
| Boxes 80 RCVD, 81 PM, 88 | Revenue use only; do not mark |
## Rules
- Joint return: enter SSNs in the same order as the first names, and in the same order every year. If your name is first, your SSN is listed first.
- Married filing separate: your name and SSN on the first line 1, your spouse's on the second line 1.
- Use your current home address; the department mails refunds and correspondence there. If the address changes before the refund arrives, file Form 822.
- Foreign address: city, province or state, and country, following that country's postal code practice; do not abbreviate the country name.
- Deceased taxpayer: print "deceased" and the date of death after the decedent's name.
- Box 97: if the last name used on this return differs from returns filed in the last four years, enter any other last names used.
- A paid preparer identification number goes in the page 2 footer, not the header.
## Example
Maria Lopez married in 2026 and now files as Maria Reyes. On the joint return she enters Reyes on line 1 and "Lopez" in box 97.
## Notes
- Form 140 line, box and page item references follow the 2025 Form 140; ADOR had not released the 2026 Form 140 when this was revised, so confirm them against it
## Required Information
- Names and SSNs (or ITINs) in the same order as last year
- Current address and daytime phone
- Extension confirmation if filing under extension
- Last names used in the last four years, if different
## Questions
- Are your names, SSNs and address current, and is the SSN order the same as last year?
- Are you filing under an extension?
- Did your last name change in the last four years?
## Common Errors
- Reversing SSN order on a joint return
- Not checking box 82F when filing after April 15 under an extension
- Marking the revenue use boxes
## Prompt
- What goes in box 97 on Form 140?
