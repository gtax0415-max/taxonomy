# Items Previously Deducted for Arizona Purposes (Page 5, D)
## Description
Arizona prohibits deducting an item more than once. If Arizona taxable income reflects a deduction of an item already deducted for Arizona purposes, add that amount to Arizona gross income.
## Example
A taxpayer subtracted $3,000 of expenses for Arizona in 2025 and the same $3,000 is deducted again in 2026 federal AGI through a carryover. Page 5, D = $3,000.
## Notes
- Form 140 line, box and page item references follow the 2025 Form 140; ADOR had not released the 2026 Form 140 when this was revised, so confirm them against it
## Required Information
- Prior Arizona returns showing the earlier deduction or subtraction
- The 2026 federal deduction for the same item
## Questions
- Is any 2026 deduction a repeat of something you already deducted or subtracted for Arizona?
## Common Errors
- Taking an Arizona subtraction and a later federal deduction for the same cost
## Prompt
- Do I add back a deduction I already used on my Arizona return?
