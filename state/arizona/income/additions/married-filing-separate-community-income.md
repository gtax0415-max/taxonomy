# Married Persons Filing Separate Returns (Page 5, A and Page 6, A)
## Description
A separate Arizona return must report one-half of the community income from all sources and all of that spouse's separate income. If you and your spouse file a joint federal return but separate Arizona returns and you begin with only the income you earned, adjust it: an increase goes on page 5, item A, and a decrease on page 6, item A. If you filed separate federal returns, each federal AGI should already be correct. Keep a schedule of how you figured the adjustment (Pub. 200; ITR 93-18, 93-19, 93-22).
## Example
Spouse A earned wages of $70,000 and Spouse B $30,000, all community income; they filed jointly federally and file separately in Arizona, each starting from his or her own wages. Each must report $50,000. Spouse A subtracts $20,000 on page 6, A; Spouse B adds $20,000 on page 5, A.
## Notes
- Form 140 line and page 5 / page 6 item letters follow the 2025 Form 140; ADOR had not released the 2026 Form 140 when this was revised, so confirm them against it
## Required Information
- Both spouses' Forms W-2, 1099 and K-1
- The joint federal return, if filed
- Records of separate property income
## Questions
- Did you file a joint or separate federal return?
- Which income is community and which is separate (for example, property owned before marriage)?
## Common Errors
- Reporting only one's own wages on a separate Arizona return
- Making the adjustment when separate federal returns already split income correctly
## Prompt
- We file separately in Arizona. How do we split our income?
