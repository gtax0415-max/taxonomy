# Nonprofit Medical Marijuana Dispensary (Page 5, J and Page 6, L)
## Description
Arizona removes the results of a nonprofit medical marijuana dispensary operated as a sole proprietorship from Arizona gross income. Net income from the dispensary that is in federal AGI is subtracted on page 6, L; a net loss that reduced federal AGI is added back on page 5, J. A dual licensee sole proprietorship (or disregarded LLC) that takes the page 6, L subtraction cannot also take the page 6, P subtraction for marijuana establishment expenses.
## Example
A sole proprietor operates a nonprofit medical marijuana dispensary that reports $40,000 of net profit on federal Schedule C: page 6, L = $40,000. If the dispensary instead had a $5,000 net loss: page 5, J = $5,000.

## Common Errors
- Taking both page 6, L and page 6, P for the same dual licensee
- Using page 6, L for a for-profit marijuana establishment
