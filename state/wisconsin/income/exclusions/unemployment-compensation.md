# Unemployment Compensation (Partial Exclusion)
## Description
Wisconsin taxes only part of unemployment compensation for lower-income filers. The excluded part is subtracted. Nonresidents: unemployment is not Wisconsin income at all.
## Worksheet (statutory base amounts, not indexed)
| Filing situation | Base amount (line 3) |
|---|---|
| Married filing jointly | $18,000 |
| Married not filing jointly, lived with spouse at any time during the year | $0 |
| Married not filing jointly, did NOT live with spouse | $12,000 |
| Single | $12,000 |
Taxable amount = smaller of (a) total unemployment compensation or (b) one-half of [FAGI − (base + taxable Social Security + taxable refunds)]. The rest is subtracted. Part-year residents prorate to the resident period (exclude railroad unemployment, which is fully exempt — see ../../deductions/retirement/).
## 2026 parameters
Same base amounts ($12,000 / $18,000 / $0); no indexing provision identified.
## Questions
- How much unemployment did you receive, and what is your filing status?
## Common Errors
- MFS filers who lived together using $12,000 instead of $0
