# Direct Deposit of the Refund
## Description
The refund can be deposited directly into a checking or savings account, or into a new or existing CollegeInvest 529 account. Without direct deposit, a check is mailed to the address on the return.

## Notes
- Confirm with the bank that it will accept the deposit
- Donations elected on the contributions schedule reduce the refund before deposit
- Example: refund $660 to checking: routing 102000021, account 4400-1187-22, type checking

## Required Information
- Routing number
- Account number
- Account type

## Questions
- Do you want direct deposit?
- To checking, savings or a CollegeInvest 529 account?

## Common Errors
- Spaces in the account number
- Wrong account type

## Prompt
- Can my Colorado refund go into a 529 account?
