# Driver License or State ID Information
## Description
Colorado asks for three items from the filer's current driver license or state ID card to help confirm identity and prevent refund fraud. The fields do not affect tax.

## Notes
- Enter only the last 4 characters of the ID number
- Example: Colorado license issued 03/14/2024, number ending 4821 → State CO, Last 4: 4821, Issue date 03/14/2024

## Required Information
- State of issue, last 4 characters, issue date (taxpayer and spouse)

## Questions
- Do you have a current driver license or state ID? Which state issued it, and when?

## Common Errors
- Entering the full ID number
- Using the expiration date instead of the issue date

## Prompt
- Why does the Colorado return ask for my driver license?
