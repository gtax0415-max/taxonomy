# Who Must File a Colorado Return
## Description
Colorado's filing requirement follows the federal one: a resident, or a nonresident with Colorado income, must file if required to file a federal return or if they owe Colorado tax.

## Notes
- The short form (DR 0104EZ) is still available for simple returns
- The consumer use tax return formerly included with the individual booklet (DR 0104US) was discontinued after 2023; use tax now goes on DR 0252
- Keep records at least 4 years after the due date; there is no time limit for assessment if no return is filed
- Example: full-year resident with $14,000 of wages, a federal filing requirement and no Colorado tax after credits still files

## Required Information
- Federal filing requirement
- Residency
- Colorado-source income

## Questions
- Are you required to file a 2026 federal return?
- Did you live in Colorado or have Colorado-source income in 2026?

## Common Errors
- Skipping the Colorado return because no Colorado tax is due
- Not filing to recover withholding
