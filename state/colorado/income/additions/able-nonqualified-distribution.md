# Nonqualified Colorado ABLE Distributions
## Description
When Colorado ABLE money is withdrawn for non-qualified purposes, Colorado recaptures the contributions that were subtracted in earlier years.

## Amount
- The nonqualified distribution, refund or withdrawal, figured under DOR's ABLE guidance

## Notes
- Example: account holder withdraws $2,500 for a vacation → add the nonqualified amount figured under DOR's guidance

## Required Information
- 1099-QA
- Use of the funds
- Prior subtractions

## Questions
- Did you take money from a Colorado ABLE account for non-disability expenses?

## Common Errors
- Treating a qualified disability expense as nonqualified

## Prompt
- Is an ABLE withdrawal taxed in Colorado?
