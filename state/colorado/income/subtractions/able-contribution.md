# Colorado ABLE Contribution Subtraction
## Description
Subtraction for contributions to a Colorado ABLE (Achieving a Better Life Experience) account for a person with a disability. SB25-302 extended it through tax year 2030.

## Amount
- Contributions up to the per-beneficiary limit
- 2026 limit: $26,200 single / $39,200 joint per beneficiary, the same limit as CollegeInvest (DOR has not yet published the 2026 figure). 2025 was $25,400 / $38,100
- Shared with CollegeInvest contributions for the same beneficiary

## Notes
- Complete the owner fields even if you or your spouse own the account
- Example: a single parent contributes $3,000 to her son's Colorado ABLE account → subtract $3,000

## Required Information
- Owner name and SSN, beneficiary, contribution totals

## Questions
- Did you contribute to a Colorado ABLE account in 2026?
- Did you also contribute to CollegeInvest for the same person?

## Common Errors
- Exceeding the combined limit with CollegeInvest
- Subtracting contributions to another state's ABLE program

## Prompt
- Are ABLE contributions deductible in Colorado?
