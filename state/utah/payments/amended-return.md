# Amended Return
## Description
A 2026 return is corrected by filing a complete new TC-40 on the 2026 forms. Lines 26 and 32 carry the original refund and payments so the amended return computes only the change.

## Reason codes (page 1)
1. Amended federal return filed (attach 1040-X); not for NOL carrybacks
2. Error on the Utah return (attach explanation)
3. IRS examination or adjustment (attach the IRS adjustment)
4. Net operating loss carryback (attach 1040-X or 1045; one return per year amended)
5. Other (attach explanation)

## Amount
- Line 26 previous refund: all refunds, credits and offsets of Utah tax received for 2026, including amounts applied to 2027 (line 40b) and deposited to my529 (line 40a). Excludes refund interest
- Line 32 previous payments: tax paid with the original return plus later tax payments for 2026. Excludes penalty, interest and fees

## Deadlines
- Within 90 days of the IRS's final determination
- Refund claims: 3 years from the original due date (plus extensions) or 2 years from payment; 3 years from the loss-year due date for an NOL carryback

## Notes
- Voluntary contributions (line 25) and my529 deposits (line 40a) cannot be changed
- Include all schedules, changed or not; do not attach the original return

## Required Information
- Original return figures, reason, federal support, refund and payment history

## Questions
- Why are you amending?
- What refund did you receive, and what did you pay, on the original return?

## Common Errors
- Code 1 for an NOL carryback (use 4)
- Leaving the 2027-applied or my529 amounts out of line 26
- Including penalty or interest on line 32

## Prompt
- I filed a 1040-X — do I need to amend my Utah return?
