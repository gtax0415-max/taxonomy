# Voluntary Contributions
## Description
Optional donations to state funds, made on the return. They INCREASE the tax due or REDUCE the refund. Up to five contributions can be entered on lines 25a–25e.

## Funds for 2026
- CN001PT Pamela Atkinson Homeless Account
- CN002PT Kurt Oscarson Children's Organ Transplant Account
- CN003PT School District and Nonprofit School District Foundation (requires a school district code)
- CN004PT Clean Air Fund
- CN005PT Governor's Suicide Prevention Fund
- CN006PT Nonprofit Capacity Fund
- CN007PT Diapering Supplies Fund
- CN008PT Statewide Hunger Relief Fund
- CN009PT School Meals Debt Relief Fund — NEW for 2026 (HB 148, 2026 General Session)
- CN010PT Citizenship Scholarship Fund — NEW for 2026 (HB 502, 2026 General Session)

## 2026 Changes
- Two new funds (CN009PT, CN010PT)
- Seven-character codes replace the old two-character codes; using an old code may cause an error
- Line moved: contributions are now line 25 (2025 return: line 28)

## Notes
- A contribution CANNOT be changed on an amended return
- Only one school district code per line, and only with CN003PT
- Separate from the Election Campaign Fund ($2 designation), which does not change tax or refund
- Separate from the my529 refund deposit (line 40a)

## Required Information
- Fund code and amount for each contribution (maximum five lines)
- School district code for CN003PT

## Questions
- Would you like to donate any of your refund or add a donation to your payment?
- Which fund(s), and how much?
- For a school foundation gift, which school district?

## Common Errors
- Entering a school district code with a fund other than CN003PT
- Using the old two-character codes
- Trying to change or remove a contribution on an amended return
- Confusing contributions with the $2 Election Campaign Fund designation

## Prompt
- I want to donate $10 to the Utah Food Bank fund on my return.
- Can I give part of my refund to my school district?
