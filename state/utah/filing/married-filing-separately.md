# Married Filing Separately
## Description
Used when spouses filed separate federal returns. Utah applies single-level or half-joint amounts and shuts off some credits that require a joint return.

## 2026 amounts
- Taxpayer tax credit base phase-out (line 15): $18,696 (same as single)
- Line 19 exempt-taxpayer worksheet standard deduction: $16,100 if the spouse did NOT itemize; $0 if the spouse itemized
- TC-150 thresholds for MFS:
  - Child Tax Credit (AN002PT): $30,500
  - Retirement Credit (AN003PT): $16,000
  - Social Security Benefits Credit (AN005PT): $45,000

## Effects on other items
- Adoption expenses credits (AN009PC, AR001PT): NOT allowed — married filers must file a joint federal return
- Domicile: spouses who both file MFS federally are NOT treated as having a spouse with Utah domicile, so one spouse's Utah domicile does not pull the other in
- Spouse's name and SSN still go on page 1

## Required Information
- Federal MFS return
- Whether the spouse itemized deductions
- Spouse's name and SSN

## Questions
- Did you and your spouse file separate federal returns?
- Did your spouse itemize?
- Is your spouse a Utah resident?

## Common Errors
- Using $16,100 on the line 19 worksheet when the spouse itemized
- Claiming a Utah adoption credit on an MFS return
- Using single-filer credit thresholds instead of the lower MFS thresholds
- Omitting the spouse's name and SSN

## Prompt
- My spouse and I file separately. How does that change my Utah return?
- My spouse itemized — what standard deduction do I use for the Utah exemption test?
