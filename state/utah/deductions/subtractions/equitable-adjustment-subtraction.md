# Equitable Adjustment (Subtraction)
## Description
Catch-all subtraction under UCA §59-10-115(2) to prevent DOUBLE TAX on an item, such as income Utah already taxed in an earlier year that appears in federal AGI again. Its mirror is the equitable-adjustment addition (AD014PT), which prevents a double benefit.

## Rules
- Enter the amount needed to prevent double Utah tax
- ATTACH an explanation (required for this subtraction)
- Do NOT use it to remove a nonresident spouse's income; file TC-40_B instead

## Notes
- Use only when no specific subtraction code (SU001PT–SU014PT) applies
- Part-year/nonresidents: TC-40_B Column A only to the extent it relates to Utah-source items

## Required Information
- Description, year, and amount of the doubly taxed item
- Written explanation

## Questions
- Is any income being taxed by Utah a second time?
- Which earlier return already taxed it?

## Common Errors
- No explanation attached
- Using it for a nonresident spouse's income
- Using it when a specific code applies

## Prompt
- Utah already taxed this income on my prior-year return, and it's in my federal AGI again.
