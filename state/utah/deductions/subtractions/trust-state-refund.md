# State Tax Refund Distributed to Beneficiary of Trust
## Description
The trust-level version of the state refund subtraction. If a Utah resident trust included a state tax refund in its federal income and distributed it to you, subtract it so Utah does not tax it.

## Amount
- The state tax refund distributed to you by a resident trust, if the refund was used to compute the trust's federal income

## Notes
- Your own state refund uses TC-40 line 5 instead (see state-tax-refund.md)
- Requires the trust to identify the refund portion of the distribution

## Required Information
- K-1 and trust statement

## Questions
- Did you receive a trust distribution that included a state tax refund the trust received?

## Common Errors
- Using line 5 for a trust-distributed refund
- Subtracting without the trust's statement

## Prompt
- My trust K-1 shows a state tax refund passed through to me.
