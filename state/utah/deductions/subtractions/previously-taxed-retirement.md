# Previously-taxed Retirement Income
## Description
Prevents double taxation when contributions to a qualified retirement plan were taxed by ANOTHER state when made, and are now taxed again by Utah when distributed. Most filers do not qualify.

## Amount
- The part of a distribution from a qualified IRC §401(a) plan, included in federal AGI, that represents amounts which, when paid into the plan, were:
  1. Not included in federal AGI, AND
  2. Taxed by another state, D.C., or a U.S. possession

## Notes
- Classic case: contributions made while working in a state that did not allow the pre-tax exclusion
- Only §401(a) plans (pension, profit-sharing, 401(k)); IRAs are not listed

## Required Information
- 1099-R
- Proof of the other state's tax on the contributions

## Questions
- Did you contribute to this retirement plan while living or working in another state that taxed those contributions?

## Common Errors
- Using it for ordinary pre-tax contributions no state taxed
- Using it for IRA distributions

## Prompt
- I worked in a state that taxed my 401(k) contributions, and now I'm retired in Utah.
