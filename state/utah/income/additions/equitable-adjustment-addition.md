# Equitable Adjustment (Addition)
## Description
Catch-all addition under UCA §59-10-115(2) to prevent a DOUBLE TAX BENEFIT, where an item would otherwise reduce Utah tax twice (for example, an item deducted on a prior Utah return that now also reduces federal AGI). Its mirror image is the equitable-adjustment SUBTRACTION (SU004PT), which prevents double tax.

## Amount
- The amount of the item that would otherwise give a second Utah tax benefit
- Taxed at the 2026 Utah rate of 4.45%

## Eligibility
- A specific item has already reduced Utah tax and is reducing it again through 2026 federal AGI
- No other specific addition code covers it

## Notes
- Use only when no specific code (AD001PT–AD013PT) applies
- Nonresidents and part-year residents: column A of TC-40_B only to the extent it relates to Utah-source items
- Keep a written explanation; the subtraction side (SU004PT) requires one to be attached

## Required Information
- Description of the item and the earlier benefit year
- Amount and documentation

## Questions
- Is any item reducing your Utah tax for a second time this year?
- Did an earlier Utah return already give you a benefit for this item?

## Common Errors
- Using this code when a specific addition code applies
- Confusing it with the subtraction (SU004PT)

## Prompt
- An item I already deducted on a prior Utah return is reducing my federal AGI again.
