# Deduction Division Between Columns
## Description
On a Mississippi COMBINED return, each spouse's income goes in a separate column, and the standard or itemized deduction and the exemption may be split between the columns in any manner. The goal is to use each spouse's $10,000 zero-rate band.
## Filing methods for married couples
- JOINT return: usually when only one spouse has income. Everything in Column A
- COMBINED return: both spouses have income. Income by spouse; deductions and exemptions split freely
- SEPARATE returns (two returns): each spouse claims half the exemption; if one itemizes, both must itemize; unused amounts cannot move between returns
## Planning point
- Each column gets its own $10,000 at 0%. Allocate deductions so that neither column wastes zero-rate room and neither goes needlessly negative
- If only one spouse has income, that income cannot be split between the columns
## Example (2026 rates)
- Spouse A taxable income before deductions $40,000; Spouse B $8,000; total deduction and exemption $16,600
- Putting all $16,600 in Column B wastes $8,600 (B goes to −$8,600, then nets against A under the negative-column rule)
- Better: Column A takes $16,600 → A taxable $23,400; B $8,000 → tax = ($23,400 − $10,000) × 4% = $536
## Required Information
- Each spouse's income
- Total deductions and exemptions available
## Questions
- Do both spouses have income?
- Will you file one combined return or two separate returns?
## Common Errors
- Splitting one spouse's income between columns
- Allocating deductions so one column goes negative unnecessarily
- On separate returns, one spouse itemizing while the other takes the standard deduction
