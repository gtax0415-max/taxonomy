# Exemption Division Between Columns
## Description
How the total exemption on line 12 is split between spouses. On a combined return the split is free; on separate returns it is exactly half each.
## Rules
- COMBINED return: the line 12 total may be divided between Column A and Column B in any manner, as long as the total is not exceeded
- SEPARATE returns: each spouse claims one-half of line 12. Any unused part on one return cannot be used on the other
- JOINT return (one spouse with income): the whole exemption goes in Column A
## Planning point
- Allocate exemptions together with deductions (see deduction-division.md) so that each column uses its $10,000 zero-rate band and neither column goes negative unnecessarily
- If the half-and-half rule on separate returns wastes exemption, a combined return is usually better
## Example (2026)
- Married, two dependents: $12,000 + $3,000 = $15,000. Spouse A has $45,000, Spouse B has $12,000, total deduction $4,600
- Put $15,000 exemption and $4,600 deduction in Column A → A $25,400, B $12,000 → tax ($15,400 + $2,000) × 4% = $696
## Required Information
- Each spouse's income
- Total exemption on line 12
## Questions
- Do both spouses have income?
- Are you filing combined or separate returns?
## Common Errors
- Claiming more than the line 12 total across both columns
- Splitting unevenly on separate returns
## Prompt
- How should we split our Mississippi exemptions between spouses?
