# Married Joint Return
## Description
One return on line 1 when ONLY ONE spouse has income. Everything goes in Column A (taxpayer).
## Amounts for 2026
- Exemption $12,000 (+ $1,500 per dependent, age 65, or blind)
- Standard deduction $4,600
- One $10,000 band at 0%, then 4%
## Notes
- If both spouses have income, use the combined method instead (same line 1), which gives each spouse a $10,000 zero-rate band
- The non-earning spouse's income cannot be created by splitting the earner's income
- Both spouses sign
## Example (2026)
- One earner, Mississippi AGI $60,000, standard deduction, two children: $60,000 − $4,600 − $15,000 = $40,400 → ($40,400 − $10,000) × 4% = $1,216
## Required Information
- The earning spouse's income documents
- Spouse name and SSN
## Questions
- Does only one spouse have income?
## Common Errors
- Using a joint return when both spouses have income (losing a $10,000 zero-rate band)
- Splitting one earner's income between columns
## Prompt
- Only I work. How do my wife and I file in Mississippi?
