# Married Filing Separate Returns
## Description
Each spouse files his or her own Form 80-105 and reports only his or her own income and deductions. Checking line 3 means BOTH spouses must file, even one with little or no income.
## Rules for 2026
- Exemption: each spouse gets HALF of line 12 ($6,000 each, plus half of any additional exemptions)
- Standard deduction: $2,300 each
- If one spouse itemizes, the other MUST itemize
- Unused exemption or deduction on one return cannot be used on the other
- Each return lists the other spouse's name and SSN
## When to use
- Rarely better than a combined return, which gets the same two zero-rate bands with free allocation. Typical reasons are legal or liability separation
- Mississippi allows separate returns even if the couple filed jointly federally
## Required Information
- Each spouse's income and deductions
- Both spouses' SSNs
## Questions
- Is there a reason to keep your returns separate?
- Will either spouse itemize?
## Common Errors
- Claiming the full $12,000 on each return
- One spouse itemizing and the other taking the standard deduction
- Only one spouse filing
## Prompt
- Should my husband and I file separate Mississippi returns?
