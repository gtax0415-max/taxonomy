# Refund Received on the Original Return
## Description
AMENDED RETURN ONLY. The refund already received, plus any amount carried forward to 2027 estimated tax, from the original 2026 return. It reduces total payments so the original refund is not paid twice.
## Rules
- Use the refund actually received, which may differ from what was claimed if the Department adjusted it or offset it for a debt
- Include the amount the original return applied to 2027 estimated tax
## Example (2026)
- Original return claimed a $600 refund; $500 received and $100 applied to 2027 → line 27 $600
## Required Information
- Original return and refund records
## Questions
- What refund did you receive on your original 2026 return?
- Did you apply part of it to 2027?
## Common Errors
- Leaving line 27 blank on an amended return
- Using the claimed refund instead of the amount received
## Prompt
- I already got a refund and now need to amend.
