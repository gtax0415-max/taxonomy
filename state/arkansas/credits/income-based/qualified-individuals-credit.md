# Additional Tax Credit for Qualified Individuals
## Description
A small credit for low net taxable income, available only on a timely filed return.

## Amounts
2025 table (revised 10/10/2025):
- $60 at net taxable income of $26,500 or less
- $5 less for each $100 band above $26,500
- $0 above $27,600

2026: indexed under Ark. Code 26-51-201(d) (3% cap). Template estimate: $60 at $27,300 or less, none above $28,400, until DFA publishes the 2026 table.

## Notes
- Status 1, 3, 5, 6: one credit from the table
- Status 2: each spouse's amount from the table, added (the joint worksheet doubles the table credit)
- Status 4: each spouse in their own column
- Timely filed returns only (including extensions)

## Required Information
- Net taxable income (line 28) for each spouse
- Filing status
- Whether the return is timely filed

## Questions
- Is your net taxable income below about $28,400?
- Will you file on time?
- What is your filing status?

## Common Errors
- Claiming it on a late return
- Using the 2025 band for 2026
- Doubling the credit on Status 4 instead of using each column

## Prompt
- Is there a low-income credit in Arkansas?
- My taxable income is about $27,000. Do I get the extra credit?
