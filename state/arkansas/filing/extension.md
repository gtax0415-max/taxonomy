# Extension of Time to File
## Description
Extends the filing deadline, not the payment deadline. A federal extension automatically covers Arkansas.

## Notes
- Federal Form 4868 automatically extends the Arkansas due date to November 15, 2027 (no need to attach it)
- Without a federal extension, file AR1055-IT by April 15, 2027; up to 210 days (November 15)
- Inability to pay is not a valid reason for an AR1055-IT extension
- Check the extension box on page 1, or no credit is given
- Tax is still due April 15, 2027. Payment made with the extension goes on line 41
- Late payment: 1% per month; late filing: 5% per month; up to 35%; interest 10% per year

## Required Information
- Whether a federal or Arkansas extension was filed
- Any payment made with it

## Questions
- Did you file a federal extension?
- Did you pay anything when you extended?
- Will you owe tax for 2026?

## Common Errors
- Not checking the extension box
- Assuming the extension delays payment
- Filing AR1055-IT when a federal extension already covers it

## Prompt
- I need more time to file my Arkansas return.
- Does my federal extension cover Arkansas?
