# Married Filing Separately on Different Returns (Status 5)
## Description
Each spouse files a separate Arkansas return. Several deductions are limited or lost under this status, so it is rarely better than Status 4.

## Notes
- Enter the spouse's name and SSN on page 1
- If either spouse itemizes, BOTH must itemize, and deductions are prorated using both spouses' incomes; attach a copy of Form AR3
- Standard deduction $2,540 (template estimate for 2026; 2025 was $2,470)
- No student loan interest deduction
- Traditional IRA phase-out range is $0–$10,000 if covered by an employer plan
- Filing requirement: gross income of $9,470 or more (2025 threshold; 2026 figure not yet published)

## Required Information
- Spouse's name, SSN, and whether the spouse itemizes
- Both spouses' AGI if itemizing

## Questions
- Why file separate returns instead of separately on the same return (Status 4)?
- Is your spouse itemizing deductions?
- Do you have student loan interest or IRA contributions?

## Common Errors
- Choosing Status 5 when Status 4 would give a lower tax
- Itemizing without prorating, or itemizing while the spouse takes the standard deduction
- Claiming the student loan interest deduction
- Leaving out the spouse's SSN

## Prompt
- My spouse and I file separate returns.
- We're separated but still married. How do we file in Arkansas?
