# Married Filing Separately on the Same Return (Status 4)
## Description
An Arkansas-only status. Both spouses file one return, but each spouse's income goes in its own column and each column is taxed separately. The two taxes are added and the credits are combined. Because of the graduated rates, this often produces less tax than filing jointly.

## Notes
- Each spouse reports their own income in column A (primary) or column B (spouse)
- Each spouse gets the standard deduction ($2,540 template estimate for 2026; $2,470 for 2025) (or both itemize)
- If ONE spouse itemizes, BOTH must itemize
- If either spouse has total NEGATIVE income, the couple must file Status 2 (jointly) instead
- Credits are combined on one return; both spouses sign
- Some limits use combined income (for example, the student loan interest test uses the joint phase-out on combined income)

## Required Information
- Income and adjustments split by spouse
- Itemized deductions split by spouse
- Jointly owned income split by ownership

## Questions
- Does either of you have a net loss for the year?
- Do you want to compare Status 2 and Status 4?
- Does either of you itemize?

## Common Errors
- Choosing Status 4 when one spouse has negative total income
- One spouse itemizing while the other takes the standard deduction
- Putting all joint income in one column
- Only one spouse signing

## Prompt
- Is it better for us to file separately on the same Arkansas return?
- My spouse and I both work. Which Arkansas status saves more?
