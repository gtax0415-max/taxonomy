# State Income Tax Refund Subtraction
## Description
A state income tax refund is federally taxable only if the taxpayer itemized and deducted state income tax in the prior year. Minnesota never allows a deduction for state income tax, so any state income tax refund included in federal AGI is subtracted on Form M1, Line 6.
## Rules
- Enter only the state income tax refund amount included on federal Schedule 1, line 1
- Property tax refunds (Form M1PR) are NOT entered here; they reduce the real estate tax deduction on Schedule M1SA instead
- Find the Minnesota refund amount through the 1099-G Refund System or by calling 651-296-4444
## Prompt
- My 1099-G shows a Minnesota refund I had to report federally.
