# Exemptions (Minnesota)
## Files in this folder
- dependent-exemptions.md — $5,300 per dependent (Form M1, Line 5)
- schedule-m1dqc.md — Schedule M1DQC rows for dependents, qualifying children, and qualifying older children
## Key point
Minnesota allows exemptions ONLY for dependents. There is no exemption for the taxpayer or spouse. (The federal personal exemption is permanently zero after OBBBA; Minnesota keeps its own dependent exemption.)
