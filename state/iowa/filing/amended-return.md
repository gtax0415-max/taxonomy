# Amended Return
## Description
To correct a filed 2026 return, file a complete IA 1040 with the amended box checked and an IA 102 Amended Return Schedule explaining each change. Since 2023 Iowa has no separate amended form.

## How it works
- Check the amended box in Step 1 and recompute the whole return with the corrected figures
- Attach IA 102 explaining what changed and why, with supporting schedules. Note any change to a credit carryforward
- Line 29: include tax PAID with earlier 2026 returns
- Line 31b: enter refunds RECEIVED (or set off against other debts) from earlier 2026 returns. Do not include amounts applied to 2027 estimated tax
- If line 31b is larger than line 31a, the difference is owed on line 34. No penalty is charged on the excess refund, but interest runs from the later of the refund date or the due date

## Deadlines and rules
- Refund claims: generally within three years of the original due date (April 30, 2027 for 2026)
- Federal changes (Form 1040-X or an IRS audit) that affect Iowa must be reported to Iowa; see IDR's "Reporting Federal Income Tax Changes to Iowa" for the deadline
- Voluntary amendments paid before IDR contacts you: interest only, no penalty
- Checkoff contributions on line 21 cannot be added, changed, or removed on an amended return
- Do not file an amended return the same day as the original, with a current-year return, or just to attach a forgotten W-2
- E-filing amended returns is allowed if the software supports it; paper amendments can take six months or more

## Required Information
- Original 2026 IA 1040 as filed
- Corrected source documents or federal Form 1040-X
- Refunds received and payments made on prior 2026 returns
- Explanation of each change

## Questions
- What changed since you filed — a new or corrected form, a federal amendment, or an IRS notice?
- How much refund did you receive, or how much did you pay, on the original return?
- Was any refund applied to 2027 estimated tax or offset against a debt?

## Common Errors
- Entering only the changes instead of a complete recomputed return
- Leaving line 31b blank so the original refund is paid twice
- Including a refund applied to estimated tax on line 31b
- Changing a checkoff contribution
- Not filing an Iowa amendment after a federal change

## Prompt
- I got a corrected 1099 after I filed my Iowa return.
- The IRS changed my federal return. Do I need to amend Iowa?
