# Married Filing Separately
## Description
Status 3 is used only when the couple filed separate FEDERAL returns. Each spouse files their own IA 1040, but some Iowa tests look at the couple's combined income.

## Rules for 2026
- Enter the spouse's name and SSN in Step 1
- Enter the spouse's net income in Step 2 when claiming the low-income exemption or the alternate tax calculation. Missing it delays refunds
- Eligibility for the low-income exemption uses BOTH spouses' combined income
- If either spouse carries a net operating loss, the other spouse cannot use the low-income exemption, unless the spouse with the loss elects not to carry it and a statement saying so is attached
- Income and deductions are split by ownership; jointly held items are generally split equally
- Dependents: each spouse reports the same dependents claimed on their federal return
- Personal credit count is 1 ($40)

## Notes
- The tax rate is a flat 3.8%, so separate filing no longer saves tax by splitting income across brackets
- Health insurance deduction $100,000 test is per return and is NOT halved for married filing separately
- Unchanged for 2026. Step references follow the 2025 IA 1040

## Required Information
- Spouse's name, SSN, and net income
- Ownership of income-producing accounts and property
- Dependents claimed on each federal return

## Questions
- Did you and your spouse file separate federal returns?
- What was your spouse's income for 2026?
- Does either of you have a net operating loss carryover?

## Common Errors
- Leaving out the spouse's net income when claiming the low-income exemption
- Testing the exemption on one spouse's income only
- Claiming dependents that don't match the federal return

## Prompt
- My spouse and I file separately. What spouse information does Iowa need?
- Can I use the low-income exemption if I file separately?
