# Line 11 Code o: Iowa ABLE Plan Non-qualified Withdrawals
## Description
Addition that recaptures earlier Iowa ABLE contribution deductions when money is withdrawn for non-qualified expenses or the account is cancelled.

## Amount
- The non-qualified withdrawal or cancellation, limited to contributions previously deducted on Iowa returns
- Column A only; attach an explanation

## Notes
- Qualified disability expenses (housing, education, transportation, health, and similar) are not added back
- A rollover from an Iowa 529 into an ABLE account counts toward the ABLE annual contribution limit
- The related ABLE contribution deduction is line 19 code ii (2026 limit tied to the Iowa 529 limit, $6,100)
- Code letters follow the 2025 instructions

## Required Information
- Form 1099-QA
- Use of withdrawn funds
- Deductions previously claimed

## Questions
- Did you withdraw from an IAble account for something other than disability expenses?
- Was the account closed in 2026?

## Common Errors
- Adding back qualified disability expense withdrawals
- Adding back more than was previously deducted

## Prompt
- I closed my IAble account. Do I owe Iowa tax?
