# Line 11 Code a: Babysitting Income
## Description
Addition for babysitting income that was NOT reported on federal Schedule C line 1. Iowa requires it to be included; it can only be an addition.

## Rules for 2026
- Add babysitting income not already in federal income
- If the income was reported on Schedule C (or as wages), nothing is added here
- Column A only; attach an explanation

## Notes
- Occasional babysitting by a teenager is the usual case; the teen may still owe no Iowa tax if a dependent filer's Iowa taxable income stays under $5,000 (see dependent-filer.md)
- Unchanged for 2026. Code letters follow the 2025 instructions

## Required Information
- Total babysitting income received in 2026
- Whether any of it was reported federally

## Questions
- Did you earn money babysitting in 2026?
- Did you report it on Schedule C or as wages on your federal return?

## Common Errors
- Adding income already reported on Schedule C
- Leaving babysitting income off both returns

## Prompt
- My daughter earned $1,800 babysitting. Does Iowa tax it?
