# Line 11 Code bb: Other Income
## Description
Catch-all code for income differences with no specific line or code.

## How to use it
- Column A: income NOT in federal taxable income that IS taxable for Iowa
- Column B: income IN federal taxable income that is NOT taxable for Iowa
- Attach an explanation naming the item and the reason

## Before using bb
- Check for a dedicated line first: U.S. interest (line 1), fund dividends (line 2), pass-through items (line 3), military retirement (line 4), Social Security (line 5), active duty pay (line 6), retirement income (line 7), railroad unemployment (line 8), depreciation (line 9)
- Then check the specific line 11 codes (a, d, h, n, o, x, y, aa, dd) and line 19 codes

## Notes
- Code letters follow the 2025 instructions

## Required Information
- Description and amount of the item
- Legal reason for the Iowa difference

## Questions
- Do you have income that is taxed differently in Iowa and isn't covered by another line?

## Common Errors
- Using bb for an item that has its own line or code
- Entering a subtraction in column A

## Prompt
- Where do I report income Iowa taxes but the IRS doesn't?
