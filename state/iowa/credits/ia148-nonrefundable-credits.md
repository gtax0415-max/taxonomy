# Other Nonrefundable Credits (IA 148 Part I)
## Description
Line 17 total of the nonrefundable credits listed by code on IA 148 Part I. Each code has its own file in ia148-codes/.

## How Part I works
- Column A: code; column B: certificate number (unless exempt)
- Column C: carryforward from 2025; column D: current-year amount earned, awarded, or passed through
- Column F: amount applied this year — total cannot exceed the Iowa tax; when several credits exceed the tax, the order follows the Iowa Administrative Code rule
- Column G: amount expiring under each code's carryforward period
- Part IV: one line for each credit received from a pass-through entity, with the entity's name and FEIN
- Complete Part V (reductions) before Parts I and II

## 2026 changes affecting Part I
- Endow Iowa (03): per-taxpayer cap $50,000
- New Jobs (08): repealed by HF 2799
- Employer Child Care (30) and Angel Investor (14): ended by SF 657; carryforwards only
- Solar (22), custom farming (24), geothermal 2017–2018 (28), housing investment (06): carryforwards only
- Historic preservation (05): no Part V reduction since 2025

## Required Information
- Every certificate and each code's carryforward balance

## Questions
- Do you have any Iowa tax credit certificates or carryforwards from earlier years?

## Common Errors
- Applying more credit than the Iowa tax
- Claiming expired carryforwards
- Missing Part IV for pass-through credits
