# IA 148 Code 24: Custom Farming Contract Tax Credit (carryforward only)
## Description
Credit for landowners who contracted with a qualified beginning farmer to custom farm their land. For 2026, only CARRYFORWARD amounts may be claimed.

## Rules for 2026
- Carryforward amounts only; no new credits on this code
- Carryforward: 10 years
- Enter the certificate number
- Current beginning farmer arrangements are claimed under code 17

## Required Information
- Certificate number and remaining balance

## Questions
- Do you have an unused custom farming contract credit?

## Common Errors
- Reporting a current beginning farmer credit here instead of code 17

## Prompt
- I have an old Iowa custom farming credit carryforward.
