# IA 148 Code 21: Redevelopment Tax Credit
## Description
Credit for qualifying investment in redeveloping brownfield or grayfield sites, awarded by the Iowa Economic Development Authority.

## Rules for 2026
- Carryforward: 5 years
- Enter the certificate number; pass-through credits need IA 148 Part IV
- Use code 67 (refundable) only if the IEDA award says it is refundable

## Required Information
- Certificate number, amount, and refundable status

## Questions
- Did your investment in a redevelopment project earn an Iowa credit?

## Common Errors
- Reporting a refundable certificate under code 21

## Prompt
- My partnership redeveloped a brownfield site and got an Iowa credit.
