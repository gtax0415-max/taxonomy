# IA 148 Code 53: Claim of Right Tax Credit
## Description
Refundable credit for income repaid in 2026 that was taxed by Iowa in an earlier year. It is the credit alternative to the line 19 code f deduction.

## Amount
- The decrease in Iowa tax for the earlier year that would result from removing the repaid income from that year's return
- Individuals and fiduciaries only; no certificate number

## Choosing credit or deduction
- Iowa's 2026 rate is a flat 3.8%; earlier years had higher rates (up to 8.53% before 2023), so the credit is often larger than the deduction
- Use one method only

## Required Information
- Repayment amount and date
- Earlier-year Iowa return for the recomputation

## Questions
- Did you repay income in 2026 that you were taxed on in an earlier year?

## Common Errors
- Claiming both the credit and the code f deduction
- Using the 2026 rate instead of the earlier year's tax

## Prompt
- I repaid $10,000 of commissions from 2021.
