# IA 148 Code 06: Housing Investment Tax Credit (Enterprise Zone)
## Description
Credit for housing developers under the former Enterprise Zone program (Iowa Code 15E.191–196, repealed in 2014). For 2026 it can appear only as a leftover carryforward.

## Rules for 2026
- Carryforward: 7 years. Credits issued in 2018 expired after 2025
- No new awards
- Enter the certificate number

## Required Information
- Certificate number, original amount, and amount used to date

## Questions
- Do you still have an unused enterprise zone housing credit?

## Common Errors
- Claiming an expired carryforward

## Prompt
- I have an old enterprise zone housing credit carryforward.
