# IA 148 Code 20: Charitable Conservation Contribution Tax Credit
## Description
Credit for donating land or a conservation easement in Iowa to a qualified organization for conservation purposes.

## Rules for 2026
- Credit equals 50% of the fair market value of the qualified real property interest donated, up to $100,000 (Iowa Code 422.11W)
- Nonrefundable; the donated amount used for the credit is not deductible for Iowa
- No certificate number; attach federal Form 8283
- Carryforward: 20 years
- The portion used for the credit cannot also be deducted: add back on Schedule 1 line 11 code dd
- Federal note: OBBBA did not repeal the federal conservation easement deduction; syndicated easement limits still apply

## Required Information
- Form 8283 and appraisal
- Deed and acknowledgment

## Questions
- Did you donate land or a conservation easement in Iowa in 2026?

## Common Errors
- Leaving out Form 8283
- Missing the code dd add-back

## Prompt
- I put a conservation easement on my Iowa farm.
