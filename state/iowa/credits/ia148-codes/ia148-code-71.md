# IA 148 Code 71: MEGA Refundable Investment Tax Credit
## Description
Refundable investment tax credit under the Major Economic Growth Attraction (MEGA) program, when the award makes it refundable. The nonrefundable version is code 31.

## Rules for 2026
- Certificate number required; claim in the year on the certificate
- Pass-through credits need IA 148 Part IV
- HF 2799 (signed June 2, 2026) extends the MEGA program's end date to January 1, 2030

## Required Information
- Certificate number and amount

## Questions
- Does your MEGA certificate state the credit is refundable?

## Common Errors
- Reporting a nonrefundable MEGA credit here instead of code 31

## Prompt
- Our MEGA credit certificate is refundable.
