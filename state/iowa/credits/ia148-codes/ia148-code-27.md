# IA 148 Code 27: Workforce Housing Investment Tax Credit
## Description
Credit for developers of qualifying housing projects in Iowa under the Workforce Housing Tax Incentives Program (Iowa Code 15.351–15.356). Usually received through a development entity.

## Rules for 2026
- Credit amount shown on the certificate issued after project completion
- Carryforward: 5 years
- Enter the certificate number; pass-through credits need IA 148 Part IV
- The program also includes a sales tax refund, which is not part of this credit

## Required Information
- Certificate number and amount

## Questions
- Did you invest in a workforce housing project that received an Iowa credit certificate?

## Common Errors
- Missing IA 148 Part IV for a pass-through credit

## Prompt
- My LLC built workforce housing and received an Iowa credit.
