# IA 148 Code 28: Geothermal Tax Credit (Installed 2017 or 2018) — carryforward only
## Description
Iowa credit for geothermal heat pump systems installed in tax year 2017 or 2018. Only CARRYFORWARDS remain.

## Rules for 2026
- Individuals and fiduciaries; corporations cannot claim it
- Carryforward only; no certificate number
- Systems installed after 2018 use code 23

## Required Information
- Installation year and remaining balance

## Questions
- Was your geothermal system installed in 2017 or 2018, and do you have unused credit?

## Common Errors
- Using code 28 for a post-2018 system

## Prompt
- I have a geothermal credit carryforward from 2018.
