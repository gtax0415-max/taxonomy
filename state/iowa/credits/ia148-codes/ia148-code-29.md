# IA 148 Code 29: Hoover Presidential Library Tax Credit (carryforward only)
## Description
Credit for gifts to the Herbert Hoover Presidential Library and Museum renovation and expansion, through its foundation, under a statewide cap.

## Rules for 2026
- Credit equals 25% of the gift, as shown on the certificate (Iowa Code 15E.364)
- New credits were available only for tax years beginning before January 1, 2025; for 2026 only CARRYFORWARDS of earlier certificates remain
- Carryforward: 5 years
- Enter the certificate number
- Add back any federal deduction for the same gift (Schedule 1 line 11 code dd)

## Required Information
- Certificate number and amount

## Questions
- Did you give to the Hoover Presidential Foundation and receive an Iowa credit certificate?

## Common Errors
- Missing the code dd add-back

## Prompt
- I donated to the Hoover Presidential Library project.
