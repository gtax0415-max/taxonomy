# IA 148 Code 23: Geothermal Heat Pump Tax Credit
## Description
Iowa credit for residential geothermal heat pump systems, tied to the federal residential credit. For 2026 it appears mainly as a carryforward.

## Rules for 2026
- Individuals only (not fiduciaries or corporations)
- Systems installed and awarded after tax year 2018: certificate number required; 10-year carryforward
- Systems installed before 2017: carryforward only; no certificate number needed
- Systems installed in 2017 or 2018 use code 28, not 23
- Federal note: the federal 25D credit, which the Iowa credit was based on, ended for expenditures after December 31, 2025. Confirm with IDR whether any new Iowa award is possible for 2026 installations

## Required Information
- Installation year, certificate number, and remaining carryforward

## Questions
- When was your geothermal system installed?
- Do you have an Iowa certificate or unused credit?

## Common Errors
- Using code 23 for a 2017–2018 system (code 28)
- Claiming without a certificate for a post-2018 system

## Prompt
- I installed a geothermal heat pump. Is there an Iowa credit?
