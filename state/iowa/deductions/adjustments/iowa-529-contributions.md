# Iowa 529 Plan Contributions (ISave 529 and Iowa Advisor 529)
## Description
Subtraction for contributions to Iowa's own 529 college savings plans. The limit applies per participant, per beneficiary account, so families can multiply it.

## Amount
- 2026 limit: $6,100 per participant per beneficiary account, up from $5,800 for 2025 (indexed annually)
- Each spouse who is a participant (account owner) gets a separate limit. Example: two parents each owning an account for each of two children can deduct up to 4 × $6,100 = $24,400
- Contributions made by April 30, 2027 (the Iowa filing deadline, not including extensions) can be elected as 2026 contributions

## Eligibility
- Only contributions to ISave 529 or Iowa Advisor 529 qualify; other states' plans do not
- You must be the account PARTICIPANT (owner). A grandparent contributing to a parent-owned account cannot deduct unless they own the account
- A rollover INTO an Iowa plan from another state's 529 plan counts toward the deduction

## Notes
- A refund of qualified expenses that is re-contributed within 60 days is not deductible and does not count toward the cap
- Non-qualified withdrawals of previously deducted amounts are added back on line 11, code d. For 2026, K-12 tuition withdrawals up to $20,000 per beneficiary are qualifying
- This line was added to the form for 2025; before that it was line 19, code g, which should no longer be used

## Required Information
- Participant name for each account
- Beneficiary name for each account
- Contributions made January 1, 2026 through April 30, 2027, with dates, and which were elected for 2026
- Rollover documentation, if any

## Questions
- Do you own an ISave 529 or Iowa Advisor 529 account?
- How many beneficiary accounts do you own, and how much did you contribute to each?
- Does your spouse own separate accounts?
- Did you contribute between January 1 and April 30, 2027 and want it counted for 2026?

## Common Errors
- Using the 2025 limit of $5,800 instead of $6,100
- Applying the limit per household instead of per participant per beneficiary
- Deducting contributions to a non-Iowa 529 plan
- Deducting a contribution made by someone who is not the account owner
- Still using line 19 code g

## Prompt
- I contributed to my kids' ISave 529 accounts.
- How much of my 529 contribution can I deduct in Iowa?
