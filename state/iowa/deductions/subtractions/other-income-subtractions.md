# Other Income Subtractions (Line 11, Column B)
## Description
Catch-all subtraction line for income items not covered on lines 1–10 that are in federal taxable income but not taxable in Iowa. Each item is reported with a letter code and an explanation.

## Subtraction codes for 2026
- aa. Premium pay: up to $1,000, to the extent in federal income, for premium pay or retention payments under the Iowa programs for designated peace officers, correctional staff, teachers, and child care workers. These were pandemic-era programs, so this code should be rare in 2026
- bb. Other income: any other item included in federal taxable income that is not taxable for Iowa (for example, interest on Iowa bonds specifically exempt by statute that was federally taxable)

## Notes
- Most line 11 codes (a, d, h, n, o, x, y, dd) are ADDITIONS and belong in column A (see other-income-additions.md)
- Many common subtractions have their own Schedule 1 line or line 19 code; use those first
- Codes follow the 2025 instructions; confirm the 2026 code list when released

## Required Information
- Documentation of each item and why Iowa exempts it

## Questions
- Did you receive premium pay or a retention bonus under an Iowa program?
- Is any income taxed federally that Iowa law specifically exempts?

## Common Errors
- Putting an addition code in column B
- Using code bb for an item with its own line (U.S. interest, retirement income, military pay)

## Prompt
- I received an Iowa teacher retention payment.
- Where do I subtract income that Iowa doesn't tax?
