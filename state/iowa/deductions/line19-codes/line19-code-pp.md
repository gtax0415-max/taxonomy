# Line 19 Code pp: Student Loan Repayments by Employers
## Description
Exclusion for income from an employer paying principal or interest on the employee's qualified education loan, whether paid to the employee or directly to the lender.

## Rules for 2026
- Federal law excludes up to $5,250 a year of employer educational assistance, including student loan payments (IRC 127). OBBBA made the student loan part permanent, with the $5,250 indexed for inflation after 2026
- Iowa subtracts only the employer payments that are INCLUDED in federal taxable income, usually the amount above the federal exclusion or payments outside a qualifying 127 plan

## Notes
- Military student loan repayments on active duty use code t
- The new Iowa Attorney Loan Repayment Program uses its own code (see line19-code-al.md)

## Required Information
- Total employer loan payments
- Amount excluded federally vs included in W-2 box 1

## Questions
- Did your employer pay any of your student loans in 2026?
- Was any of it included in your W-2 wages?

## Common Errors
- Subtracting the first $5,250 that was already excluded federally
- Using this code for military or attorney program repayments

## Prompt
- My employer paid $8,000 toward my student loans.
