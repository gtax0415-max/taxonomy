# Line 19 Code a: Accrual Method (Installment Gain Already Taxed)
## Description
Subtraction for 2026 installment-sale gain that is in federal income this year but was already fully reported to Iowa in an earlier year. It prevents Iowa from taxing the same gain twice.

## Rules for 2026
- Applies only when the entire gain was reported for Iowa in a prior year (for example, the taxpayer elected out of installment reporting for Iowa)
- Subtract the installment gain recognized federally in 2026 on Form 6252
- Interest received on the installment note is still taxable and is not subtracted

## Notes
- If the gain qualified for the Iowa capital gain deduction, that deduction is claimed through IA 100 on line 16 each year, not here
- Code letters follow the 2025 instructions

## Required Information
- Form 6252 for 2026
- Prior-year return showing the full gain reported for Iowa

## Questions
- Are you receiving installment payments on an earlier sale?
- Did you report the whole gain on your Iowa return in the year of the sale?

## Common Errors
- Subtracting installment gain that was never reported for Iowa
- Subtracting the interest portion of payments

## Prompt
- I sold property on contract and reported the full gain to Iowa years ago.
