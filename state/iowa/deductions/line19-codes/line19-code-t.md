# Line 19 Code t: Military Exemptions (Military Student Loan Repayments)
## Description
IDR's servicemember guidance places military student loan repayments on code t. They are exempt from Iowa tax if the member is on active duty when the repayment is made.

## Rules for 2026
- Subtract military student loan repayments included in federal taxable income, made while the member was on active duty
- Other military items have their own lines:
  - Active duty pay → Schedule 1 line 6
  - Military retirement and Survivor Benefit Plan → line 4
  - Retirement plan withdrawals by national guard or reserve members called to duty → line 11, code cc
  - Combat zone pay → already excluded federally

## Required Information
- Repayment amounts and dates
- Active duty status on those dates

## Questions
- Did the military repay any of your student loans in 2026?
- Were you on active duty when the repayment was made?

## Common Errors
- Using code t for active duty pay or military retirement, which have their own lines
- Subtracting repayments made after leaving active duty

## Prompt
- The Army paid off part of my student loans this year.
