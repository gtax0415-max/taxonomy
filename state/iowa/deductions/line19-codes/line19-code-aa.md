# Line 19 Code aa: Victim Compensation Awards
## Description
Subtraction for payments crime victims receive, to the extent they are in federal taxable income.

## What qualifies
- Victim compensation awards paid through the Iowa Department of Justice program (Iowa Code 915.81)
- Victim restitution payments received under Iowa Code chapters 910 and 915
- Damages awarded by a court and received by the victim in a civil action against the offender

## Notes
- Many such payments are already excluded federally (for example damages for physical injury); only amounts in federal taxable income are subtracted
- Code letters follow the 2025 instructions

## Required Information
- Type and amount of each payment
- Whether it was included in federal income

## Questions
- Did you receive victim compensation, restitution, or a court award against an offender in 2026?

## Common Errors
- Subtracting an amount already excluded federally
- Subtracting an insurance settlement that is not victim compensation

## Prompt
- I received restitution from a court case. Is it taxed in Iowa?
