# Line 19 Code w: Biodiesel Production Refund
## Description
Exclusion for the Iowa biodiesel production refund received by an Iowa biodiesel producer, to the extent it is included in federal income.

## Rules for 2026
- Subtract the refund received in 2026 that is reported in federal income
- Producers organized as pass-through entities report it through the entity's Iowa statement (Schedule 1 line 3), not here

## Notes
- The refund is a business item; few individual returns use this code
- Confirm the refund program remains in effect for 2026 production

## Required Information
- Refund amounts received and how they were reported federally

## Questions
- Do you own a biodiesel production business that received an Iowa production refund?

## Common Errors
- Subtracting an entity-level refund on the owner's line 19 instead of line 3

## Prompt
- My biodiesel plant received an Iowa production refund.
