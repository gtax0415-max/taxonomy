# Line 19 Code ii: Iowa ABLE Savings Plan Contributions
## Description
Deduction for contributions to an IAble account, Iowa's ABLE plan for individuals with disabilities.

## Amount
- Up to the maximum allowed per beneficiary for the Iowa 529 plan: $6,100 for 2026 ($5,800 for 2025)
- Interest and earnings in the account are exempt from Iowa tax

## 2026 changes to watch
- Federal: starting in 2026, ABLE eligibility expands to people whose disability began before age 46 (was 26), so more Iowans can open accounts
- Federal annual ABLE contribution limit follows the gift tax exclusion; a 529 rollover into ABLE counts toward it

## Notes
- Non-qualified withdrawals of deducted amounts are added back on line 11 code o
- Only contributions to Iowa's plan qualify

## Required Information
- 2026 contributions and beneficiary
- Contributor (the person deducting must have made the contribution)

## Questions
- Did you contribute to an IAble account in 2026?
- Who is the beneficiary?

## Common Errors
- Using the 2025 limit ($5,800)
- Deducting contributions to another state's ABLE plan
- Deducting a 529 rollover that was already deducted when first contributed to the 529

## Prompt
- I contributed to my son's IAble account.
