# Line 19 Code dd: Other Federal Adjustments (IA 126 Only)
## Description
Used ONLY by nonresidents and part-year residents filing IA 126, to carry federal adjustments to income (federal Schedule 1, Part II, before federal AGI) that are not taken elsewhere on IA 126.

## Scope for this taxonomy
- OUT OF SCOPE: the team's 2026 scope is full-year residents only (team decision 2026-09-30). Full-year residents never use code dd, because those adjustments are already in federal taxable income on line 2
- Keep as a review row so a nonresident or part-year return is flagged

## Required Information
- Federal Schedule 1 Part II, if IA 126 applies

## Questions
- Were you a nonresident or part-year resident of Iowa in 2026?

## Common Errors
- A full-year resident using code dd and deducting federal adjustments twice

## Prompt
- What is line 19 code dd on the Iowa return?
