# Line 19 Code FH: FirstHome Iowa Program Contributions (SF 2472, 2026)
## Description
New deduction for contributions to FirstHome Iowa, the state homebuyer savings program created by SF 2472 (signed May 18, 2026). It replaces the 2017 First-Time Homebuyer Savings Account program.

## Rules for 2026
- Deduction: up to $5,500 per beneficiary per year for contributions made on or after July 1, 2026, adjusted annually for inflation
- Interest and earnings in the account are excluded from Iowa income
- Run by the Treasurer of State through the FirstHome Iowa Program Trust
- Qualified use: down payment and closing costs for a single-family home in Iowa used as the buyer's homestead, bought at least one year after the account is opened
- Old program: no new First-Time Homebuyer Savings Accounts on or after July 1, 2026. Existing balances can move into FirstHome Iowa without penalty or Iowa tax if deposited within 30 days
- Old program limit for 2026: the fiscal note gives a 2026 maximum of $4,744 (this appears to be the married-filing-jointly figure; the single figure would be half). Contributions made to an existing account before July 1, 2026 use code j under those rules

## Open items
- Whether the $5,500 limit applies per contributor per beneficiary or per beneficiary in total, and how it interacts with code j contributions in the same year, should be confirmed on the 2026 instructions
- The official 2026 code letter has not been published; "FH" is the template's placeholder

## Required Information
- FirstHome Iowa contributions by date and beneficiary
- Any old-program contributions in 2026 and any transfer into FirstHome Iowa

## Questions
- Did you contribute to a FirstHome Iowa account after July 1, 2026?
- Did you also contribute to an older first-time homebuyer account earlier in 2026?
- Who is the beneficiary of each account?

## Common Errors
- Deducting contributions made before July 1, 2026 under the new program
- Treating a transfer from an old account as a new deductible contribution
- Missing the 30-day window when moving an old account into FirstHome Iowa
- Exceeding $5,500 per beneficiary

- I opened a FirstHome Iowa account for my daughter.
- What happens to my old Iowa first-time homebuyer savings account?
