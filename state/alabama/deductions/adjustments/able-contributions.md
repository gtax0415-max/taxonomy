# ABLE Account Contributions
## Description
Alabama-only deduction for contributions to an Alabama ABLE savings account for a person with a disability. Code of Alabama §40-18-15.8.

## Amounts
- Up to $5,000 per taxpayer per year
- Up to $10,000 on a joint return only if BOTH spouses contribute
- Unchanged for 2026

## 2026 status
- Act 2025-402 extended the deduction through tax years beginning before January 1, 2031
- Federal annual ABLE contribution limit for 2026 is $19,000 (the gift tax exclusion); the Alabama deduction cap stays $5,000

## Notes
- Only Alabama ABLE accounts qualify
- A non-qualified withdrawal is added back to income plus 10%

## Required Information
- Contributions by each spouse
- Account owner (beneficiary)

## Questions
- Did you contribute to an Alabama ABLE account?
- Did both spouses contribute?

## Common Errors
- Deducting more than $5,000 per contributor
- Deducting an out-of-state ABLE account

## Prompt
- Are ABLE contributions deductible in Alabama?
