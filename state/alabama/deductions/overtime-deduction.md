# Qualified Overtime Compensation Deduction
## Description
NEW for 2026. Deduction for the premium portion of overtime pay, up to $1,000 per taxpayer. Code of Alabama §40-18-15(a)(29), added by Act 2026-604 (HB 527, signed April 16, 2026). Allowed whether or not the taxpayer itemizes.

## Amount
- Qualified overtime compensation as defined in IRC §225: only the PREMIUM above the regular rate (for example, the "half" in time-and-a-half)
- Capped at $1,000 per taxpayer, not indexed
- Tax years 2026 through 2028
- Per ALDOR guidance (May 13, 2026), the premium is the amount in W-2 box 12 code TT; total overtime wages stay in box 16

## Notes
- Different from the old Alabama overtime exclusion, which ended June 30, 2025
- The federal overtime deduction (up to $12,500) does not carry over to Alabama; Alabama allows only this $1,000
- "Per taxpayer" indicates each spouse on a joint return may claim up to $1,000; confirm on the 2026 form
- Not one of the deductions replaced by the standard deduction

## Example
An hourly worker with $4,992 of qualified overtime premium (box 12 code TT): deduction is $1,000.

## Required Information
- W-2 box 12 code TT amount for each spouse

## Questions
- Does your W-2 show an amount in box 12 code TT?
- Did your spouse also earn overtime?

## Common Errors
- Deducting all overtime pay instead of the premium
- Deducting more than $1,000 per taxpayer
- Applying the expired 2024–2025 full overtime exclusion

## Prompt
- Is overtime deductible in Alabama in 2026?
