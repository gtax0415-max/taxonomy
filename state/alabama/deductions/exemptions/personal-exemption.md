# Personal Exemption
## Description
A fixed exemption set by filing status (Code of Alabama §40-18-19(a)(8)). Not reduced by income.

## Amounts (unchanged for 2026)
- Single: $1,500
- Married filing jointly: $3,000
- Married filing separately: $1,500 for each spouse
- Head of family: $3,000

## Notes
- Status determined as of December 31
- Part-year residents get the full exemption
- A person claimed as someone else's dependent still gets it
- A filer with both a part-year and a nonresident return claims it only on the part-year return

## Example
A joint return claims $3,000.

## Required Information
- Filing status

## Questions
- What is your filing status?

## Common Errors
- Claiming $3,000 as single
- A dependent leaving it off

## Prompt
- What is the Alabama personal exemption?
