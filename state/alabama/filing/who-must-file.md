# Who Must File
## Description
A full-year Alabama resident must file Form 40 when gross income EXCEEDS the top standard deduction plus the personal exemption for their filing status (Code of Alabama §40-18-27(a)). Because the threshold is built from those two amounts, it changes only when they change.

## Amounts (2025 thresholds; no 2026 change enacted)
| Filing status | Gross income threshold | (Standard deduction + exemption) |
|---|---|---|
| Single | $4,500 | $3,000 + $1,500 |
| Married filing jointly | $11,500 | $8,500 + $3,000 |
| Married filing separately | $5,750 | $4,250 + $1,500 |
| Head of family | $8,200 | $5,200 + $3,000 |

## Notes
- The test uses GROSS income (all taxable income before deductions), not AGI
- Part-year residents use the same amounts, counting only income received while a resident
- Anyone with Alabama tax withheld should file to get it back, even below the threshold
- Nonresidents file Form 40NR when Alabama-source income exceeds the prorated exemption
- The older figures ($4,000 / $10,500 / $5,250 / $7,700) applied before 2022

## Example
A single worker with $9,828 of wages must file ($9,828 is over $4,500).

## Required Information
- Filing status
- Total gross income

## Questions
- What was your total gross income for 2026?
- What is your filing status?
- Was Alabama tax withheld from your pay?

## Common Errors
- Using the pre-2022 thresholds
- Testing AGI instead of gross income
- Not filing to recover Alabama withholding

## Prompt
- Do I need to file an Alabama return?
