# Married Filing Jointly
## Description
Filing status 2, used when the federal return is married filing jointly.

## Rules
- Both spouses' names, SSNs, and dates of birth, in the same order as the federal return
- Both spouses sign
- 2026 standard deduction: $25,676 (2025: $25,000)

Example: a married couple with two W-2s files status 2 and takes $25,676.

## Notes
- Authority: R.S. 47:294. $25,676 reflects the 2.7% CPI-U adjustment; LDR's 2026 withholding tables used a preliminary $25,750. Confirm the final figure with LDR (the "RIB 26-019" cited earlier could not be located)
- Joint filers get doubled limits on some exemptions (for example, START and ABLE deposits)

## Required Information
- Both spouses' identification

## Questions
- Are you filing a joint federal return?

## Common Errors
- Only one spouse signing
- Listing spouses in a different order than the federal return

## Prompt
- What standard deduction does a joint return get?
