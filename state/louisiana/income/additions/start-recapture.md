# Recapture of START Contributions
## Description
START (Louisiana's 529 college savings plan) contributions exempted in earlier years are added back when they are refunded, or withdrawn and not used for qualified higher-education expenses.

## Rules
- Add back the amount of previously exempted contributions refunded or withdrawn for non-qualified purposes in 2026
- Withdrawals used for qualified higher-education expenses are not added back

Example: $1,000 of earlier exempted START deposits refunded in 2026 → add $1,000.

## Notes
- Authority: R.S. 47:293(9)(a) (START exemption and add-back) and R.S. 17:3095. Unchanged for 2026
- The START contribution exemption is code 09E

## Required Information
- Amount refunded or withdrawn and its use
- Prior exempted contributions

## Questions
- Did you take money out of a START account in 2026?
- Was it used for college expenses?

## Common Errors
- Adding back qualified withdrawals
- Adding back contributions never exempted

## Prompt
- I withdrew money from my child's START account.
