# Recapture of START K12 Contributions
## Description
START K12 is Louisiana's savings program for elementary and secondary education expenses. Contributions exempted in earlier years are added back when refunded or withdrawn for anything other than qualified K–12 education expenses.

## Rules
- Add back previously exempted contributions withdrawn or refunded for non-qualified purposes in 2026
- Contribution exemption (code 28E) remains $1,200 per beneficiary ($2,400 joint) for 2026, with carryforward. A 2025 bill (SB 13) to double it did not pass

Example: a $500 non-qualified START K12 refund → add $500.

## Notes
- Authority: R.S. 17:3100.1 et seq.; R.S. 47:293(9)(a)
- START K12 funds used for K–12 expenses cannot also be claimed under the school-expense deductions

## Required Information
- Withdrawals and their use
- Prior exempted contributions

## Questions
- Did you withdraw from a START K12 account in 2026?
- Was the money used for qualified K–12 expenses?

## Common Errors
- Adding back qualified withdrawals
- Confusing START K12 with the college START plan (Line 2B)

## Prompt
- I took money out of a START K12 account.
