# START Saving Program Contributions (Code 09E)
## Description
Deposits into a START account (Louisiana's 529 college savings plan) are exempt up to an annual limit per beneficiary.

## Amount
- $2,400 per beneficiary ($4,800 per beneficiary on a joint return)
- Doubled ($4,800 / $9,600) for irrevocable donations to a resident beneficiary whose family federal AGI is under $30,000 or who qualifies for free school lunch
- Deposits over the limit carry forward per account while the account stays open
- Cannot reduce income below zero

Example: joint filers deposit $6,000 for one child → $4,800 exempt, $1,200 carried forward.

## Notes
- Authority: R.S. 47:293(9)(a) and R.S. 17:3095. Unchanged for 2026
- START K12 deposits are a different code (28E, $1,200 / $2,400)
- Non-qualified withdrawals are added back on Schedule E Line 2B

## Required Information
- Deposits by beneficiary
- Carryforward balance

## Questions
- Did you deposit into a START account in 2026?
- How many beneficiaries?
- Do you have unused exemption from earlier years?

## Common Errors
- Applying the joint limit on a single return
- Confusing START with START K12

## Prompt
- I put money in my child's Louisiana 529. Is it deductible?
