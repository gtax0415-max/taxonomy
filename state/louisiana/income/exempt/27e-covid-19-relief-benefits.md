# COVID-19 Relief Benefits (Code 27E)
## Description
State or federal COVID-19 relief grants, loans, rebates, credits, or advance refunds included in federal AGI are exempt in Louisiana.

## Rules
- Subtract only amounts included in federal AGI
- Attach a schedule listing each source and amount

## Notes
- Authority: R.S. 47:293(9)(a)(xx) and R.S. 47:297.16. Still in law for 2026, but almost no 2026 income should qualify
- Examples from earlier years: Main Street Recovery grants, Frontline Worker hazard pay rebates

## Required Information
- Source and amount of each payment

## Questions
- Did you receive any COVID-19 relief payment in 2026 that was included in federal income?

## Common Errors
- Subtracting payments not included in federal AGI
- Using 27E for unrelated disaster aid

## Prompt
- What is code 27E?
