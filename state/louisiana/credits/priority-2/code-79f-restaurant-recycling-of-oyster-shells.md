# Restaurant Recycling of Oyster Shells (Code 79F)
## Description
Refundable credit for restaurants that donate oyster shells to an approved recycling program (used to rebuild oyster reefs).

## Amount
- $1 for every 50 pounds of shell donated
- Up to $2,000 per restaurant per year
- Statewide $100,000 per calendar year, first-come, first-served, prorated for same-day requests
- No credit for tax years beginning after December 31, 2028

## Notes
- Authority: R.S. 47:6043. Unchanged for 2026
- LDR requires its own claim form; that state form is not a source document here

## Required Information
- Pounds donated
- Recycling program name

## Questions
- Does your restaurant donate oyster shells to a recycling program?
- How many pounds in 2026?

## Common Errors
- Claiming more than $2,000 per restaurant
- Donating to a program that is not approved

## Prompt
- My restaurant recycles oyster shells.
- What is code 79F?
