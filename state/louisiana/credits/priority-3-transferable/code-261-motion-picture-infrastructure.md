# Motion Picture Infrastructure (Code 261)
## Description
Carryover-only code for the former credit for building film production infrastructure (studios, post-production facilities).

## Status for 2026 — carryover only, likely expired
- No infrastructure credits certified after July 1, 2017
- If the general five-year motion picture carryforward applies, balances have probably expired before 2026 (NOT confirmed; check the holder's certification for its carryforward period)

## Notes
- Authority: former R.S. 47:6007 infrastructure provisions
- LDR requires the certification attached

## Required Information
- Certification date, amount, and remaining balance

## Questions
- Do you hold an unused motion picture infrastructure credit, and when was it certified?

## Common Errors
- Claiming an expired balance
