# Other Transferable Credit (Code 299)
## Description
Catch-all code for a transferable credit that has no code of its own. LDR describes it only as reserved for future credits.

## Notes
- No new transferable credit was enacted for 2026; the 2025 credits (public school donations, fortified roof, work-based learning) are not transferable and have their own codes
- Whether the New Markets credit expanded by Act 441 of 2025 is transferable was not confirmed
- Recheck when the 2026 IT-540 is released

## Required Information
- Name and authority of the credit
- Certification number and amount

## Questions
- Do you hold a transferable Louisiana credit not on the code list?

## Common Errors
- Using 299 for a credit that has its own code
- Omitting the certification number

## Prompt
- What is code 299?
