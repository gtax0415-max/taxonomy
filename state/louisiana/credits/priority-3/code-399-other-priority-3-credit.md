# Other Priority 3 Credit (Code 399)
## Description
Catch-all code for a priority 3 nonrefundable credit that has no code of its own. LDR describes it only as reserved for future credits.

## Notes
- CORRECTION: the donation to public schools credit (Act 423 of 2025) does NOT go here. LDR Revenue Information Bulletin 25-031 assigns it code 195 on the priority 1 schedule (Schedule C). See code-195 file
- No 2026 credit has been identified that requires code 399. The 2026 Regular Session enacted no new income tax credits, and the 2025 credits have their own codes (195, 466, 467)
- Recheck when the 2026 IT-540 is released

## Required Information
- Name and legal authority of the credit
- Certificate or approval amount

## Questions
- Do you have a Louisiana credit not on the Schedule J code list?

## Common Errors
- Using 399 for a credit that has its own code
- Putting the public school donation credit here instead of code 195

## Prompt
- I have a Louisiana credit with no code.
- What is code 399?
