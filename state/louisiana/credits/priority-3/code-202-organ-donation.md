# Organ Donation (Code 202)
## Description
Carryover-only code for the former credit for living organ donors' expenses.

## Status for 2026 — carryover only
- Act 403 of the 2017 Regular Session ended the credit effective December 31, 2019; no new credit since 2020
- LDR allows the remaining balance to be used within the 10-year carryover period, so credits from 2019 or earlier can last until about 2029

## Notes
- The underlying statute, R.S. 47:297, was later repealed in full by Act 11 of the 2024 Third Extraordinary Session for periods beginning January 1, 2025. LDR instructions still allow the carryover; confirm code 202 remains on the 2026 code list
- Very rare

## Required Information
- Year the credit was earned
- Amount used each year since

## Questions
- Do you have an organ donation credit carried over from 2019 or earlier?

## Common Errors
- Claiming a new credit for a donation after 2019
- Using a carryover past 10 years

## Prompt
- I still have an organ donation credit from years ago.
- What is code 202?
