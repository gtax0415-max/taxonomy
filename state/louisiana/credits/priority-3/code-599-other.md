# Other (Code 599)
## Description
Catch-all code placed after the 500-series credits (mostly business carryforwards). LDR describes it only as reserved for future credits.

## Notes
- LDR documents no functional difference between 399 and 599 beyond their position in the code list
- No 2026 credit has been identified that requires code 599
- Recheck when the 2026 IT-540 is released

## Required Information
- Name and legal authority of the credit
- Certificate or approval amount

## Questions
- Do you have a Louisiana credit not on the Schedule J code list?

## Common Errors
- Using 599 for a credit that has its own code

## Prompt
- What is code 599?
