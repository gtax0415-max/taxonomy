# Other Priority 1 Credit (Code 199)
## Description
Catch-all code for a priority 1 nonrefundable credit that has no code of its own. Reserved for credits created after the form was printed.

## Amount
Whatever the authorizing statute or certificate allows. Code 199 carries no amount rule of its own.

## Notes
- No 2026 credit has been identified that requires code 199; recheck when the 2026 IT-540 is released
- If a dedicated code exists for the credit, use that code instead

## Required Information
- Name of the credit and its legal authority
- Certificate or approval amount
- Share of a pass-through credit from the K-1

## Questions
- Do you have a Louisiana credit that does not appear on the Schedule C code list?
- Did an agency issue you a certificate for it?

## Common Errors
- Using 199 for a credit that has its own code
- Using a priority 3 or refundable credit code on Schedule C

## Prompt
- I have a Louisiana tax credit that isn't on the list.
- What is credit code 199?
