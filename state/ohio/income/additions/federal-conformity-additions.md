# Federal Conformity Additions
## Description
This line is only for federal conformity adjustments published at tax.ohio.gov/conformity. Do not enter federal Schedule A adjustments here.
## Amount
The conformity add-back listed in the current Ohio conformity guidance.
## Required Information
- Current conformity release from tax.ohio.gov/conformity
## Questions
- Did Ohio decouple from a federal provision this year?
## Common Errors
- Putting itemized deductions on this line
- Leaving the line blank when a conformity bulletin requires an add-back
