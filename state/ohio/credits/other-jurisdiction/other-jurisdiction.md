# Other-Jurisdiction Credits
## Description
Two nonrefundable credits that keep Ohio from taxing the same income twice, or from taxing income that was never Ohio-sourced. They print after every other nonrefundable credit.

Which one applies is not a clean either/or:

| Residency | Nonresident credit (line 38) | Resident credit (line 39) |
|---|---|---|
| Full-year resident | No | Yes |
| Part-year resident | Yes, for income earned while a resident of the other state | Yes, for non-Ohio income earned while an Ohio resident and taxed by another state |
| Full-year nonresident | Yes | No |

A part-year resident can claim BOTH on the same return. Do not treat the nonresident credit as the only option for a part-year mover.
