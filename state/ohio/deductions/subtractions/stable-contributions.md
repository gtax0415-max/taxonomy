# STABLE Contributions
## Description
Deduct contributions to a STABLE (Ohio ABLE) account, up to $4,000 per beneficiary per year. Excess carries forward, still capped at $4,000 per beneficiary per year. Married taxpayers share one $4,000 cap per beneficiary, whether joint or separate.
## Amount
Up to $4,000 per beneficiary this year, plus unused prior-year contributions within that same annual cap.
## Required Information
STABLE account statements; beneficiary identification; prior-year unused amounts. Worksheet at tax.ohio.gov/faq-STABLE.
## Questions
- How much did you contribute per beneficiary?
- Do you have unused contributions from last year?
## Common Errors
- Deducting $4,000 per spouse on top of $4,000 per beneficiary
- Deducting another state's ABLE plan
## Prompt
- I funded an Ohio STABLE account.
