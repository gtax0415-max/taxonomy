# Amended Return Payments and Overpayment
## Description
Two lines used ONLY on an amended 2026 K-40. They carry forward what already happened on the original return so the amended return shows only the change.

## Lines
- LINE 24: money remitted with the original 2026 return, including a pending direct debit scheduled with it
- LINE 26: overpayment shown on the original return. It was either refunded or credited forward, so it is SUBTRACTED from total payments. Enter as a positive number; negative entries are not accepted

## Line 27 on an amended return
Lines 19 through 25, minus line 26.

## Example
Original return: tax $3,000, withholding $3,400, refund $400. Amended return: tax $3,250, withholding $3,400. Line 26 = $400. Line 27 = $3,400 − $400 = $3,000. Underpayment = $250, plus interest from the original due date.

## Notes
- Do not enter these on an original return
- Payments made with the original return are not the same as estimated payments (line 20)

## Required Information
- Amount paid with the original return
- Refund or credit forward shown on the original return

## Questions
- Is this an amended return?
- How much did you pay with the original return?
- What refund or credit forward did the original return show?

## Common Errors
- Leaving line 26 blank, so the original refund is paid again
- Counting the original payment on both line 20 and line 24
- Using the refund actually received instead of the original return's overpayment amount

## Prompt
- I am amending my Kansas return and already got a refund.
- What do I put on lines 24 and 26?
