# Massachusetts Retirement Income
## Description
Massachusetts taxes retirement income very differently from the federal return. Social Security is fully exempt, many government pensions are exempt, and because Massachusetts never allowed an IRA deduction, IRA distributions are taxable only after previously taxed contributions are recovered.
