# Massachusetts Wages
## Description
Wages, salaries, tips and other employee compensation reported on Forms W-2, taxed as 5.0% Part B income on Form 1, Line 3. Use the Massachusetts state wage figure (W-2 Box 16), which can differ from federal Box 1.
