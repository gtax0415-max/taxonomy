# Massachusetts Procedures and Administrative Forms
## Description
Forms that are not income, deductions, credits or taxes, but control how a return is filed, corrected, disputed or refunded.
## Files in this folder
| File | Form | Federal counterpart | Use |
|---|---|---|---|
| abatement-form-abt.md | Form ABT | Form 843 (roughly) | Dispute an assessment, request penalty waiver |
| innocent-spouse-relief.md | Form 84 | Form 8857 | Relief from joint liability |
| nondebtor-spouse-claim.md | Form M-8379 | Form 8379 | Recover your share of a joint refund taken for your spouse's Massachusetts tax debt |
| deceased-taxpayer-refund.md | Form M-1310 | Form 1310 | Claim a refund due a deceased taxpayer |
| taxpayer-disclosure-statement.md | Schedule TDS | Form 8275 (roughly) | Disclose and explain positions and differences |
| amended-returns.md | Form 1 (amended ovals) | Form 1040-X | Change a filed return; report federal/other-state/BBA changes |
| electronic-filing.md | M-8453, M-9325, EFO, PV | Forms 8879 / 8453 | E-file declarations, paper-filing opt-out, payment voucher |
## Which form to use
- To CHANGE your own return (or report a federal change) → file an AMENDED return (amended-returns.md), NOT Form ABT
- To DISPUTE what DOR assessed or to ask for penalty relief → Form ABT
- Spouse's understatement on a joint return → Form 84 (with Form ABT if already assessed)
- Joint refund intercepted for spouse's Massachusetts tax debt → Form M-8379
