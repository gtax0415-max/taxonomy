# Amended Returns
## Description
To change anything on a filed Massachusetts return, file a complete new Form 1 (or 1-NR/PY) with the Amended return oval filled in. Include ALL schedules filed with the original, even unchanged ones, plus a statement explaining each change by line and amount.
## Lines specific to amended returns
- Line 36: overpayment shown on the original return (original Line 52)
- Line 42: tax paid with the original return (original Line 55)
- Estimated payments stay on Line 40 as originally reported
- An overpayment applied to the next year on the original (Line 53) cannot be changed
## Time limit
Generally within three years of the date the original return was filed.
## Reporting federal and other-state changes
Massachusetts requires reporting of federal changes (amended federal returns, IRS audits, BBA partnership audit adjustments) and other-jurisdiction changes by filing an amended return with the appropriate oval.
## Amended return treated as an abatement application
An amended return reducing tax may be treated as an abatement application; filing gives DOR consent to act after six months. Withdrawing consent makes the request deemed denied at the later of six months or the withdrawal date (TIR 16-11).
## P.L. 119-21 conformity relief (2025 returns)
Taxpayers who applied federal P.L. 119-21 provisions (IRC 163(j), 168(n), 174/174A, 179, 1400Z-2) before the June 12, 2026 supplemental budget can avoid penalties and interest on resulting underpayments by filing an amended 2025 return (or original if on extension) within 90 days of enactment, with Schedule M-2210 and a Schedule TDS stating "Taxpayer is applying for relief related to Massachusetts conformity with the provisions of federal law P.L. 119-21" and explaining each adjustment.
## Mailing
Same addresses as original returns: PO Box 7000 (refund/no payment) or PO Box 7003 (payment), Boston, MA 02204. Do NOT attach Form ABT.
## Questions
- What is changing, and why?
- Was there a federal amended return, IRS audit, or other-state change?
- When was the original return filed?
## Common Errors
- Filing only the changed schedules
- Using Form ABT to amend
- Not reporting a federal audit change
- Moving estimated payments to Line 42
## Prompt
- I forgot to claim the rental deduction last year.
- The IRS changed my federal return.
