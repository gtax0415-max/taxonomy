# Who Must File
## Description
Whether a Missouri return is required, or worth filing to get withholding back.

## Amounts for 2026
- Not required to file federally → generally not required in Missouri
- A federal filer may not need to file if: a resident with Missouri AGI under $1,200; a nonresident with Missouri income under $600; or Missouri AGI less than the standard deduction for the filing status
- 2026 standard deductions: $16,100 single/MFS; $24,150 head of household; $32,200 married filing combined

## Eligibility
- Every potential filer

## Notes
- File anyway to claim a refund of Missouri withholding or a refundable credit (property tax credit uses MO-PTC if no return is required)
- Example: single filer with $9,000 of wages and Missouri withholding files to get the withholding back

## Required Information
- Federal filing requirement
- Missouri AGI or Missouri-source income
- Missouri withholding

## Questions
- Are you required to file a federal return?
- What is your Missouri adjusted gross income?
- Did Missouri withhold tax?

## Common Errors
- Not filing to recover withholding
- Adding a per-dependent amount to the threshold (Missouri has none)

## Prompt
- Do I have to file a Missouri return?
