# Amended Return
## Description
A corrected return filed on Form MO-1040 with the Amended Return box checked. There is no separate amended form.

## Amounts for 2026
- Line 46: amount paid with the original return
- Line 47: overpayment shown (or adjusted) on the original return
- Line 48: line 45 + line 46 − line 47
- Reason boxes: A federal audit; B net operating loss carryback; C investment tax credit carryback; D other correction

## Eligibility
- Any filer correcting a 2026 return

## Notes
- Report federal changes within 90 days of the final federal determination; missing it extends DOR's time to assess
- Refund claim deadline: 3 years from filing or 2 years from payment, whichever is later (1 year from a federal change notice for federal changes)
- Attach Form 1040-X or the federal audit report
- Example: $400 paid with the original, no original overpayment → line 48 = line 45 + $400

## Required Information
- Reason for amending and related dates
- Original payment and overpayment

## Questions
- Are you correcting a return already filed? Why?
- Did the IRS change your federal return?

## Common Errors
- Omitting the amount paid with the original return
- Missing the 90-day federal change deadline

- How do I amend my Missouri return?
