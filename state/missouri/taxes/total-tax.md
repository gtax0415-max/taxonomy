# Balance, Subtotal and Total Tax
## Description
Each spouse's tax after the resident credit or income percentage, plus other taxes, then the two spouses' amounts added together.

## Amounts for 2026
- Line 33 = line 30 − line 31, or line 30 × line 32
- Line 35 = line 33 + line 34
- Line 36 = line 35Y + line 35S
- MO-TC credits are limited to each spouse's line 35 (unless refundable)

## Eligibility
- Every return

## Notes
- For in-scope full-year residents with only Missouri income, line 31 = $0 and line 32 = 100%, so line 33 = line 30
- Example: line 35Y $1,200 + line 35S $800 → line 36 $2,000

## Required Information
- Lines 30–34 for each spouse

## Questions
- None (computed)

## Common Errors
- Using both MO-CR and MO-NRI for the same spouse
