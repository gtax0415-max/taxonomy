# Income Percentages and Taxable Income Split
## Description
On a combined return, each spouse's share of Missouri AGI is turned into a percentage, and the combined amount after deductions is split by those percentages so each spouse's tax is figured separately.

## Amounts for 2026
- Line 7: each spouse's share, rounded to a whole percent; the two must total 100%
- If one spouse's Missouri AGI is negative: 0% for that spouse, 100% for the other
- Line 26 = line 6 − line 25; if less than zero, enter $0
- Line 27 = line 26 × each spouse's line 7 percentage

## Eligibility
- Every return (single filers use 100%)

## Notes
- No change for 2026
- Example: line 5Y $70,000, line 5S $30,000 → 70% and 30%

## Required Information
- Lines 5Y, 5S, 6, 25

## Questions
- None (computed)

## Common Errors
- Percentages that do not add to 100%
- Entering a negative line 26

- How do I compute the Missouri income percentages?
