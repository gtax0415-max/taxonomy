# Property Tax Credit Claim (Form MO-PTC)
## Description
The stand-alone version of the property tax credit for a person who is not required to file a Missouri income tax return (for example, someone whose only income is Social Security). Same eligibility, limits, and chart as MO-PTS.

## Amounts for 2026
- Identical to MO-PTS: income limits $38,200 / $42,200 / $41,000 / $48,000; spouse exemption $2,800 / $5,800; caps $1,055 rent and $1,550 property tax; chart step 1/16% per $495 above $14,300
- 2026 chart not yet published

## Eligibility
- Same as MO-PTS
- Not required to file Form MO-1040 (a person who must file MO-1040 claims on MO-PTS instead)

## Notes
- The whole credit is refunded, since there is no income tax to offset
- Can be filed up to 3 years after the original due date
- If the claimant died, the person filing may need a death certificate and the DOR form for claiming a deceased person's refund

## Required Information
- Same as MO-PTS

## Questions
- Do you need to file a Missouri income tax return this year?
- If not, do you meet the age, disability, or survivor test?

## Common Errors
- Filing MO-PTC when an MO-1040 is required
- Using 2025 limits

## Prompt
- I only get Social Security; can I still get the Missouri property tax credit?
