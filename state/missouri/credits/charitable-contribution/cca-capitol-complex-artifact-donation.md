# Capitol Complex – Artifact Donation (MO-TC code CCA)
## Description
Nonrefundable credit for donating an artifact to the Missouri State Capitol Complex. Monetary donations use a separate code (CCM) with different rules.

## Amount
- 30% of the artifact's value as set by the Board of Public Buildings
- No per-taxpayer limit
- Statewide: $10 million per calendar year, shared between CCA and CCM

## Eligibility
- Board of Public Buildings accepts the artifact
- Any income taxpayer, including individuals

## Notes
- Carryforward: 4 years; DED says credits must be redeemed within 5 years of issuance
- Transferable
- Sunset: August 28, 2027; 2026 is covered
- Contrast CCM: 50% of a cash donation and REFUNDABLE

## Required Information
- DED certificate and benefit number
- Board valuation
- Carryforward used in prior years

## Questions
- Did you donate an artifact (not money) to the Capitol Complex?
- What value did the Board of Public Buildings assign?

## Common Errors
- Using your own appraisal instead of the Board's value
- Using 50% (the monetary rate) for an artifact
- Coding a cash gift as CCA instead of CCM

## Prompt
- I donated an artifact to the Missouri State Capitol.
