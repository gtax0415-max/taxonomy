# Combat Pay Included in Federal AGI
## Description
Military pay earned while serving in a combat zone that is still included in federal AGI. This usually happens for officers whose pay exceeds the highest enlisted-pay exclusion.

## Amounts for 2026
- The combat-zone pay included in W-2 box 1
- No change for 2026

## Eligibility
- Missouri home-of-record service member who served in a combat zone

## Notes
- Not the W-2 box 12 code Q amount; code Q is combat pay already excluded federally
- Reported as a checkbox on MO-A line 11
- Example: $30,000 of combat pay included in box 1 → subtract $30,000

## Required Information
- Combat-zone months and pay included in box 1

## Questions
- Did you serve in a combat zone in 2026?
- Was any of your combat pay included in W-2 box 1?

## Common Errors
- Subtracting the box 12 code Q amount (already excluded)

## Prompt
- Is combat pay taxed in Missouri?
