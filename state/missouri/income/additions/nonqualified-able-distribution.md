# Nonqualified ABLE Distribution
## Description
An ABLE withdrawal not used for qualified disability expenses (or not held for the minimum period) is added back: previously subtracted contributions plus earnings.

## Amounts for 2026
- Previously subtracted contributions + earnings in the nonqualified withdrawal
- No change for 2026

## Eligibility
- Contributor (or beneficiary if the contributor has died) with a nonqualified distribution

## Notes
- Qualified disability expenses are not added back
- Example: $1,000 nonqualified ABLE withdrawal → add $1,000

## Required Information
- Distribution amount and use
- Contributions subtracted in prior years

## Questions
- Did you take an ABLE withdrawal that was not for disability expenses?

## Common Errors
- Adding back qualified withdrawals

## Prompt
- Is an ABLE withdrawal taxable in Missouri?
