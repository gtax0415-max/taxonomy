# Other Additions (Schedule ADJ, Lines 2b-2c, code 99)
## Description
Code 99 is the catch-all addition for any income not included in federal adjusted gross income that is taxable in Virginia and is not covered by Schedule ADJ, Line 1, Line 2a or another addition code (10, 11, 12, 14, 17, 18, 19 or 20).
## What to enter
- The amount of any other income not included in federal AGI which is taxable in Virginia
- Enter code 99 on Line 2b or 2c, followed by the amount
## Explanation required
- Paper filers: enclose an explanation and supporting documentation, if applicable
- Electronic filers: provide a detailed explanation in the space provided by the software program
## Questions
- Do you have income that was excluded from your federal return but that Virginia taxes, and that does not fit one of the listed addition codes?
## Common Errors
- Using code 99 for an item that has its own code or line (for example, other-state bond interest belongs on Line 1)
- Omitting the explanation
## Prompt
- I have an unusual item that Virginia taxes but the federal return doesn't.
