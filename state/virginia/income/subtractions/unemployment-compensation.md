# Unemployment Compensation Benefits (Schedule ADJ, Lines 6b-6d, code 37)
## Description
Unemployment compensation is taxable on the federal return. Virginia allows a subtraction for unemployment compensation benefits taxable under IRC 85 that were reported as income on the federal return, using code 37 (Va. Code § 58.1-322.02, subdivision 17). Benefits from any state's program qualify.
## What to enter
- The amount of unemployment compensation benefits received during the taxable year and reported as income on your federal income tax return
- Enter code 37 on Line 6b, 6c or 6d, followed by the amount
## Related
Railroad Unemployment Insurance Act benefits are listed under code 22, not code 37. The same income may not be included in more than one subtraction.
## Required Information
- Unemployment compensation reported on the 2026 federal return, for each spouse
## Questions
- Did you receive unemployment benefits in 2026 (Form 1099-G)?
- Did you report them on your federal return?
## Common Errors
- Subtracting more than was reported federally
- Reporting railroad unemployment benefits under both code 22 and code 37
## Prompt
- I was laid off and collected unemployment this year.
