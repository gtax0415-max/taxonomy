# Federal Partnership Income Subtraction (Schedule ADJ, Lines 6b-6d, code 59)
## Description
Income related to a federal partnership audit may be subtracted from Virginia taxable income if the income was previously reported on the owner's Virginia return, using code 59. It is the reverse of addition code 19.
## What to enter
- The federal taxable income that was included in the owner's original Virginia return but should not have been reported
- Enter code 59 on Line 6b, 6c or 6d, followed by the amount
## What to enclose
A copy of the partnership's Form 502FED-1.
## Questions
- Did a federal partnership audit reduce income that you already reported on your original Virginia return?
- Did the partnership give you Form 502FED-1?
## Common Errors
- Claiming the subtraction without enclosing Form 502FED-1
- Using code 59 when the audit increased income (addition code 19)
## Prompt
- An IRS partnership audit reduced my share of income that I had already reported to Virginia.
