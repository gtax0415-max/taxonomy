# Locality Code and Mailing Addresses (Form 760 header)
## Description
Every Form 760 carries a three-digit locality code for the Virginia city or county where you lived on January 1, 2027. Local school funding is allocated based in part on this code. The same list gives each locality's mailing address and phone number, because a paper return can be mailed to the local Commissioner of the Revenue or directly to the Department of Taxation.
## How to find the code
Look up the city or county in "2026 Income Tax Return Mailing Addresses and Locality Codes" (instructions, pages 39-40) and enter the number in the Locality Code boxes. Use the locality of residence on January 1, 2027, not where you work. Examples from the list:
| Locality | Code |
|---|---|
| Arlington County | 013 |
| Chesterfield County | 041 |
| Fairfax County | 059 |
| Henrico County | 087 |
| Loudoun County | 107 |
| Prince William County | 153 |
| Alexandria City | 510 |
| Norfolk City | 710 |
| Richmond City | 760 |
| Virginia Beach City | 810 |
Note that a county and a city of the same name have different codes (for example Fairfax County 059 and Fairfax City 600; Richmond County 159 and Richmond City 760; Roanoke County 161 and Roanoke City 770).
## Where to mail a paper return
- Directly to the Department of Taxation: refund returns to P.O. Box 1498, Richmond, VA 23218-1498; tax due returns to P.O. Box 760, Richmond, VA 23218-0760.
- Or to your Commissioner of the Revenue at the address listed. Many localities (for example Fairfax County, Henrico County, Arlington County and Richmond City) list the two Department boxes instead of a local address.
- Do not mail a return to P.O. Box 1115; that address is for information requests only.
- If you file locally and pay by check, make it payable to the Treasurer or Director of Finance of your city or county; otherwise to the Department of Taxation.
- Local offices (Commissioner of the Revenue, Director of Finance, Director of Tax Administration) also give information and return preparation assistance; phone numbers are in the list.
- e-File is preferred; if you e-file, do not mail a paper copy.
## Questions
- What city or county did you live in on January 1, 2027?
- Is your paper return a refund or a balance due?
## Common Errors
- Using the locality where you work or where you lived during 2026 instead of on January 1, 2027
- Confusing a county with the independent city of the same name
- Mailing a tax due return to the refund box, or any return to P.O. Box 1115
## Prompt
- What is my locality code? I live in Virginia Beach.
- Where do I mail my Virginia return if I owe money?
- I moved from Fairfax to Richmond in December; which code do I use?
