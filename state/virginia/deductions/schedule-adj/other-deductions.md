# Other Deductions (Schedule ADJ, Line 8a-8c, code 199)
## Description
A catch-all code for any other deduction from Virginia adjusted gross income that the taxpayer is entitled to claim and that has no specific code (101-119). Because there is no printed rule behind it, the explanation is required.
## How to claim
- Enter code 199 and the amount on Schedule ADJ, Line 8a, 8b or 8c (or on Schedule ADJS if more than three deductions).
- Paper return: enclose an explanation and supporting documentation, if applicable.
- Electronic return: provide a detailed explanation in the space provided by the software.
## When not to use it
- An item with its own deduction code (101-119) goes under that code.
- Income that is not taxable in Virginia but is in federal AGI is a subtraction (Schedule ADJ, Lines 4-6, including code 99 Other), not a deduction.
- Itemized deductions go on Virginia Schedule A.
## Required Information
- Description and amount of the deduction
- The Virginia law that allows it
- Confirmation that no specific code, subtraction or Schedule A line covers it
## Questions
- What is the deduction, and what Virginia law allows it?
- Is it already covered by a specific code, a subtraction or Schedule A?
- Do you have documentation to enclose?
## Common Errors
- Using code 199 for an item that has a specific code
- Claiming a subtraction as a deduction or vice versa
- Omitting the explanation
## Prompt
- I have a Virginia deduction that isn't on the list. How do I claim it?
