# Utility Interconnect Triggering Project Expense Deduction (Schedule ADJ, Line 8a-8c, code 119)
## Description
New for taxable years beginning on and after January 1, 2026: a deduction for the amount paid or cost incurred for installing a qualifying upgrade required to interconnect a triggering project. "Qualifying upgrade" and "triggering project" have the meanings in Va. Code section 56-596.5. The deduction is Va. Code § 58.1-322.03, subdivision 19. Code 119 is this taxonomy's assignment; confirm it on the final 2026 Schedule ADJ.
## Amount
The amount paid or cost incurred to install the qualifying upgrade. No dollar cap is stated.
## Conditions
- The upgrade is a qualifying upgrade required to interconnect a triggering project, as defined in Va. Code section 56-596.5.
- No deduction is allowed for a taxpayer who has claimed a deduction under Va. Code section 58.1-402 for the same amount paid or cost incurred.
## Required Information
- Amount paid or cost incurred in 2026 for the qualifying upgrade
- Utility documentation identifying the upgrade and the triggering project
- Whether the same cost was deducted by a corporation or pass-through entity under § 58.1-402
## Questions
- Did you pay for a utility upgrade required to interconnect a project in 2026?
- Does the utility treat it as a qualifying upgrade for a triggering project?
- Was the same cost deducted under Va. Code section 58.1-402?
## Common Errors
- Claiming the deduction for costs incurred before 2026
- Claiming the same cost under both this deduction and Va. Code section 58.1-402
