# Charitable Mileage (Schedule ADJ, Line 8a-8c, code 111)
## Description
Virginia allows 18 cents per mile for charitable driving. The mileage deduction taken on Schedule A stays there; code 111 adds the DIFFERENCE between 18 cents per mile and the charitable mileage deduction per mile allowed on Virginia Schedule A. A taxpayer who used actual expenses and whose actual expenses were less than 18 cents per mile may deduct the difference between actual expenses and 18 cents per mile.
## How to compute
(18 cents - per-mile rate allowed on Virginia Schedule A) x charitable miles.

The 2026 booklet does not state the Schedule A per-mile rate; use the federal charitable mileage rate actually allowed on Schedule A. If that rate is 18 cents or more, there is no code 111 deduction.
## Eligibility
- The driving was for a charitable organization and the mileage deduction is allowed on Virginia Schedule A.
- The instruction ties the computation to the amount allowed on Virginia Schedule A, which implies the taxpayer itemizes; confirm before claiming for a non-itemizer.
## Questions
- How many miles did you drive for charity, and do you have a log?
- Did you use the standard mileage rate or actual expenses on Schedule A?
## Common Errors
- Deducting the full 18 cents per mile instead of only the difference
- Claiming the difference when the Schedule A rate is not below 18 cents
## Prompt
- I drive a lot for my church. Is there a Virginia mileage deduction?
