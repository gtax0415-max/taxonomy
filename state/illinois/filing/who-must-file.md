# Who Must File an Illinois Return
## Description
The filing tests for 2026. Two things stand out: a resident who had to file federally must file in Illinois no matter how small the Illinois liability, and ANYONE with Illinois withholding or estimated payments must file to get it back — there is no automatic refund.
## Residents
File if you were required to file a federal return, OR if you were not but your Illinois base income (Line 9) exceeds your exemption allowance ($2,925 single; $5,850 joint; plus $1,000 per age-65 or blindness box and $2,925 per dependent for 2026).
## Residents in specific situations
- Worked in Iowa, Kentucky, Michigan, or Wisconsin: file and include that compensation as Illinois income; recover any tax those states withheld from THEM, not through Illinois
- Retired: file if you filed federally, even though Line 5 will usually eliminate the tax
- Claimed as a dependent on someone else's return: file if base income exceeds $2,925 or to recover withholding. A child's Form 8814 income reported by the parent does not count
- Students: no exemption from filing and no special residency rule; federally nontaxable scholarships stay nontaxable
- Nonresident aliens: file if federally taxable; attach federal Form 1040-NR
- Surviving spouse or representative: file whatever return the decedent would have owed
## Part-year residents
File IL-1040 with Schedule NR if you earned income from ANY source while a resident, earned Illinois-source income while a nonresident, or want a refund of Illinois withholding.
## Nonresidents
File IL-1040 with Schedule NR if Illinois base income (Schedule NR Line 46) exceeds the prorated exemption (Schedule NR Line 50), or to recover Illinois tax withheld in error (attach an employer letter). Exception: a nonresident whose only Illinois income is from partnerships, S corporations, or trusts that withheld enough Illinois tax to cover the liability need not file.
## Reciprocal-state residents working in Illinois
Iowa, Kentucky, Michigan, and Wisconsin residents owe no Illinois tax on Illinois wages, salaries, tips, and commissions. File Schedule NR only for OTHER Illinois-source income — Illinois lottery winnings, Illinois unemployment, business or rental income — or to recover withholding.
## Always file to recover
Illinois tax withheld from pay, estimated payments made, and pass-through withholding on a K-1-P or K-1-T are refunded only on a filed return.
## Required Information
- Whether a federal return was required
- Illinois base income and exemption count
- Residency status and dates
- Illinois withholding on W-2s, 1099s, K-1-Ps
## Questions
- Were you required to file a federal return?
- Were you an Illinois resident all year, part of the year, or not at all?
- Did anyone withhold Illinois tax from you, or did you make estimated payments?
- Can someone else claim you as a dependent?
## Common Errors
- Skipping the return because Line 5 wipes out the tax, when a federal filing requirement forces an Illinois filing
- Not filing to recover withholding "because I don't owe anything"
- A Wisconsin resident filing an Illinois return for wages alone
- A dependent with $3,000 of base income assuming no filing is needed
