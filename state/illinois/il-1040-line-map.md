# Form IL-1040 Line Map — every line to its file
## Description
Confirmation that every line of the IL-1040 is covered, and where. Built from the 2025 form (R-12/25), which is the latest issued; the 2026 form is expected to keep the same line numbers. Adjustments to a line — additions, subtractions, exemptions, credits, recapture — are listed in the file for that line.

## 2026 parameters used throughout
Rate 4.95% · exemption $2,925 (+$1,000 age 65, +$1,000 blind) · exemption and credit cliff $500,000 joint / $250,000 other · 529 and ABLE subtractions $10,000 / $20,000 each · EITC 20% of federal, investment income cap $12,200 · Child Tax Credit 40% of Illinois EITC · property tax credit 5% · K-12 credit 25% over $250, max $750 · volunteer emergency worker $500 · use tax 6.25% / 1%, ST-44 above $600 / $1,200 · estimates required above $1,000, safe harbor 90% / 100% · return due April 15, 2027, extended October 15, 2027
