# Form D-400 Line Map
## Description
Crosswalk of EVERY item on Form D-400 to the taxonomy file that covers it. Line numbers follow the 2025 D-400; NCDOR publishes 2026 forms in January 2027. The 2026 return is due April 15, 2027 and uses a 3.99% rate.

## Lines 17 and 19
- Line 17 = Line 15 − Line 16. Credits can never push this below zero because D-400TC, Line 20 cannot exceed Line 15
- Line 19 = Line 17 + Line 18. Consumer use tax is added AFTER credits, so nonrefundable credits cannot offset it
## Attachments checklist
| Attach | When |
|---|---|
| W-2s, 1099s showing NC withholding | Any amount on Line 20 |
| 1099-R | Bailey deduction (Schedule S, Line 20) |
| DD-214, 1099-R, or similar | Uniformed services retirement deduction (Schedule S, Line 21) |
| Schedule S (both pages) | Any entry on Line 7 or Line 9 |
| Form NC-NOL | NC NOL on Schedule S, Line 39 |
| Schedule A | Itemized deductions on Line 11 |
| Schedule PN | Taxable percentage on Line 13 |
| Schedule PN-1 (both pages) | Entry on Schedule PN, Line 17e or 19h |
| D-400TC, NC-478, NC-Rehab | Any credit on Line 16 |
| Other state's return and proof of payment | Out-of-state tax credit |
| NC K-1 | Line 21c or 21d |
| Federal return | If it does not show a North Carolina address and was not e-filed |
| Schedule AM | Amended return |
