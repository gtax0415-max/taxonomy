# Filing Status
## Description
California uses the same five filing statuses as federal law (Form 540, lines 1–5): single, married/RDP filing jointly, married/RDP filing separately, head of household, and qualifying surviving spouse/RDP. Generally use the same status as the federal return; if no federal return was required, use any status the filer would have been entitled to federally. Main exceptions: registered domestic partners (single or HOH federally, married/RDP in California) and certain spouses who file jointly federally but separately for California (see married-rdp-filing-jointly.md).
