# Amended Returns (Form IT-40, Amended Box)
## Description
To correct a 2026 individual income tax return after it was filed, prepare another Form IT-40 reflecting all changes and place an "X" in the "Amended" box on the front page. Include a copy of all required schedules reflecting the changes and documentation; failure to do either can delay processing. File the amended return electronically if possible.
## Payments and refunds on an amended return
- All amounts previously paid (for example, the balance paid with the original return) are reported as an estimated payment (Schedule 5, line 4).
- Refunds previously received are not reported on the amended filing.
- If an amended return reports additional tax and you previously received a refund, DOR issues a notice of proposed assessment or a demand for payment for repayment of the refund plus interest and penalty.
## When amending is needed
- A federal change to AGI or other items (federal amended return or IRS adjustment).
- Conformity: if you added back federal changes with code 120 because Indiana had not yet adopted them, and Indiana later adopts them, file an amended return to recoup the add-back.
- Research and experimental expenditures: a taxpayer making the P.L. 119-21 retroactive election must amend all Indiana returns on which code 154 modifications were reported (SEA 243; see income/add-backs/research-experimental-expenditures-154.md).
- Refund claims are subject to the statute of limitations (see due-dates-and-extensions.md).
## Example
Original 2026 return: tax $2,400, withholding $2,000, $400 paid with the return. Later a missed $1,000 1099 adds $30 of state tax (2.95%) plus county tax. The amended IT-40 shows the corrected tax, withholding $2,000 on Schedule 5, lines 1-2, the $400 earlier payment on Schedule 5, line 4, and the remaining balance due.
## Questions
- What changed from the return you originally filed, and why?
- How much did you pay with the original return, and did you receive a refund?
- Did you also amend your federal return?
## Common Errors
- Forgetting the Amended box
- Reporting only the changed lines instead of a complete return
- Showing the prior refund as a payment
- Leaving out the payment made with the original return
