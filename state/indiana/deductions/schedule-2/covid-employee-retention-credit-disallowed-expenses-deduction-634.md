# COVID-related Employee Retention Credit Disallowed Expenses Deduction (Schedule 2, Line 11, Code 634)
## Description
If you had a deduction disallowed for federal purposes because an employer claimed a federal COVID-related employee retention credit, deduct the amount that was disallowed federally and that otherwise would have been allowable in determining Indiana adjusted gross income. The 2025 booklet lists this deduction as reinstated for 2025.
## Rules
- Report it only if the federal deduction was disallowed and/or required to be added to federal AGI in the current year.
- Do not deduct amounts disallowed for non-COVID employee retention credits, such as disaster-related credits.
- If the amounts relate to 2020, 2023 or 2024, or come through a Schedule IN K-1 reporting Code 147, use Code 147 instead of Code 634.
## 2026 note
The booklet's NOL code list shows code 634 for 2021 to 2022 and 2025. Confirm against the 2026 form whether code 634 remains available for 2026.
## Example
A sole proprietor's 2026 federal wage deduction was reduced by $10,000 because of a COVID-related employee retention credit (2025 amount; confirm against the 2026 form). Code 634 = $10,000, if the code remains on the 2026 form.
## Questions
- Did your business (or a pass-through you own) claim the COVID-related employee retention credit, and was a wage deduction disallowed or added back this year?
## Common Errors
- Using code 634 for disaster-related retention credits
- Using code 634 when the item belongs under Code 147
