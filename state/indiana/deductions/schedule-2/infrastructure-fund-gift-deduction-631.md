# Infrastructure Fund Gift Deduction (Schedule 2, Line 11, Code 631)
## Description
A deduction is available for certain contributions made to a regional development infrastructure fund. Keep detailed records of the contribution; DOR can request them.
## Example
A $1,000 gift to a qualifying regional development infrastructure fund (2025 amount; confirm against the 2026 form). Code 631 = $1,000.
## Questions
- Did you contribute to a regional development infrastructure fund? Do you have records of the gift?
## Common Errors
- Claiming ordinary charitable gifts under code 631
## Prompt
- I gave to a regional infrastructure fund. Is there an Indiana deduction?
