# Employer Student Loan Payment Interest Deduction (Schedule 2, Line 11, Code 637)
## Description
If you must add back employer-paid student loan payments using Code 148 on Schedule 1, you may deduct the student loan interest that was paid by your employer and that you would have been permitted to deduct if federal law did not disallow the deduction.
## Amount
- Complete Worksheet 4-1 in IRS Publication 970 to find the additional interest allowable for Indiana, not more than $2,500 (2025 amount; confirm against the 2026 form) total.
- When completing Worksheet 4-1, do not add back amounts required to be added back using Code 148.
- The deduction cannot exceed the Code 148 add-back.
See Income Tax Information Bulletin #6.
## Example
An employer paid $3,000 of a worker's student loan, excluded from federal income; the worker adds back $3,000 with Code 148. Of the payment, $900 was interest that Worksheet 4-1 shows would be deductible. Code 637 = $900.
## Questions
- Did your employer pay on your student loans, and did you add the payments back with Code 148?
- How much of the employer payment was interest?
## Common Errors
- Claiming code 637 without a Code 148 add-back
- Deducting more than the Code 148 amount or more than $2,500
## Prompt
- My employer pays my student loans. Is any of it deductible in Indiana?
