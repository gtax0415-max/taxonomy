# Conformity Add-Back - Negative Entry (Schedule 1, Line 6, Code 147)
## Description
Code 147 is a negative conformity modification. It generally arises from conformity issues from a previous year, or from deductions enacted by Indiana legislation passed retroactively to earlier years (the 2025 booklet says "years before 2025"; for the 2026 return read as years before 2026). In rare cases it arises in the current year when the IRC treats an item as taxable or nondeductible that was previously exempt or deductible and Indiana has not adopted the change.
## Entry
Schedule 1, line 6: name "Conformity Add-Back," code 147, amount as a negative number.
## Example
A federal law enacted after January 1, 2026 makes a $2,000 benefit taxable federally for 2026, and Indiana has not adopted it. Federal AGI includes the $2,000; enter Conformity Add-Back, 147, -2000.
## Questions
- Did any prior-year conformity add-back reverse this year?
- Did a federal change after January 1, 2026 increase your federal AGI?
## Common Errors
- Entering code 147 as a positive amount
- Using 147 for a current-year item that reduces federal AGI (that is code 120)
