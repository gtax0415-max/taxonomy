# Conformity Add-Back - Positive Entry (Schedule 1, Line 6, Code 120)
## Description
Indiana uses the Internal Revenue Code as of a fixed date. For 2026 that date is January 1, 2026 (SEA 243); the 2025 booklet used January 1, 2023. If federal legislation enacted after the conformity date modifies federal AGI and Indiana has not adopted it, the IRC used for Indiana income differs from the IRC used for federal income. Code 120 is only for:
- current-year conformity issues, and
- add-backs required by Indiana legislation passed retroactively to earlier years (the 2025 booklet says "years before 2025"; for the 2026 return read as years before 2026).
Conformity issues from preceding tax years go on the add-back line specific to the item.
## When uncertain
If it is uncertain whether Indiana will adopt federal legislation passed after the conformity date that modifies federal AGI, you may add back those items as an "other" add-back. If Indiana later adopts them, file an amended return to recoup the add-back.
## Entry
Schedule 1, line 6: name "Conformity Add-Back," code 120, amount (positive).
## Example
A federal law enacted in mid-2026 creates a new above-the-line deduction of $1,200 that Indiana has not adopted. Enter Conformity Add-Back, 120, 1200. If Indiana adopts the change in 2027, file an amended 2026 return removing it.
## Questions
- Did any federal law enacted after January 1, 2026 change your federal AGI?
- Has DOR issued updated conformity guidance?
## Common Errors
- Using code 120 for an item that has its own add-back line
- Using code 120 for a prior-year conformity issue
- Forgetting to amend when Indiana adopts the change
## Prompt
- A new federal tax law passed this year. Does Indiana follow it?
