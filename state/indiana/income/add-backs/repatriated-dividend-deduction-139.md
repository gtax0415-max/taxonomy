# Federal Repatriated Dividend Deduction Add-Back (Schedule 1, Line 6, Code 139)
## Description
Untaxed foreign earnings and profits treated as repatriated dividends must be reported for Indiana. Add back the deduction taken on federal Form 965, line 17. Income Tax Information Bulletin #116 has more detail. This mainly concerns the IRC 965 transition years and is rare on a 2026 individual return.
## Example
An individual shareholder of a foreign corporation reports a Form 965, line 17 deduction of $7,500 → code 139 = $7,500.
## Questions
- Do you own shares of a foreign corporation and file Form 965?
## Common Errors
- Adding back the gross 965 inclusion instead of the deduction
## Prompt
- I have a Form 965 deduction. Does Indiana allow it?
