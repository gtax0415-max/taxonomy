# Modifications from Excess Inclusion Income (Schedule 1, Line 6, Code 153)
## Description
Use code 153 if you have a current-year federal net operating loss that does not appear in federal taxable income because you report excess inclusion income under IRC 860E, and you have Indiana modifications that are allowable in figuring your Indiana NOL. Report the amount of modifications allowable in figuring the portion of the NOL not already part of AGI. In most cases this equals the excess inclusion income. Use the inverse of the sign of the underlying modifications. Also complete Schedule NOL-MOD, Part 2.
## Do not report code 153 if
- the amount determined is positive (net deductions exceed net add-backs), or
- you do not have a federal net operating loss.
## Example (2025 booklet)
Individual A has $100 of excess inclusion income, a $20,000 bonus depreciation add-back and a $50,000 federal NOL. Report $20,000 on line 4 and -100 with code 153. Together the modifications produce a $30,000 Indiana NOL.
## Questions
- Do you hold a REMIC residual interest with excess inclusion income?
- Do you have a current-year federal NOL and Indiana add-backs?
## Common Errors
- Reporting a positive code 153 amount
- Using code 153 without a federal NOL
