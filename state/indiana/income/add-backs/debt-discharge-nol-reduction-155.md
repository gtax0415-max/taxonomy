# Discharge of Debt Reduction of Net Operating Losses (Schedule 1, Line 6, Code 155)
## Description
If you have an Indiana net operating loss carryforward that must be reduced because of discharges of debt excluded from federal gross income (reported on Schedule NOL-MOD), list an amount necessary to use up the NOL carryforwards.
## How to figure it
1. Complete the return as normal.
2. Determine how much NOL carryforward must be used because of the debt discharge.
3. Enter on code 155 the amount needed to make Schedule 2, line 9 equal to the Indiana NOLs allowed for the current year plus the Indiana NOLs required to be reduced because of the debt discharge.
Complete Schedule NOL-MOD before entering an amount for code 155. Code 155 is excluded from the 100-series add-backs used on Schedule IT-40NOL, line 2.
## Example
Indiana NOL carryforward $50,000; current-year income allows $20,000 on Schedule 2, line 9; $15,000 of excluded debt discharge must reduce the NOL. Schedule 2, line 9 must show $35,000, so code 155 = $15,000.
## Questions
- Did you exclude canceled debt from federal income (Form 982)?
- Do you have Indiana NOL carryforwards?
## Common Errors
- Entering code 155 without completing Schedule NOL-MOD
- Reducing the carryforward without the matching Schedule 2, line 9 entry
## Prompt
- I had canceled debt excluded federally and an Indiana NOL. What do I report?
