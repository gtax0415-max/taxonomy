# Add-Backs (Schedule 1, Lines 1-7)
## Description
Schedule 1 lists amounts deducted or excluded in figuring federal AGI that Indiana treats differently. The total on Schedule 1, line 7 is entered on Form IT-40, line 2 and added to federal AGI on line 3. Some entries can be negative (bonus depreciation in later years, code 147, code 151, code 153, catch-up modifications, a PTET refund on line 1). Keep the federal forms and schedules behind each add-back; DOR can ask for them. Enclose Schedule 1 (enclosure sequence 01).
## How the lines flow
```
Line 1   Tax add-back (taxes based on or measured by income deducted on federal Schedules C, C-EZ, E, F; PTET)
Line 2   Net operating loss carryforward deducted federally (Schedule 1 "Other income" line, line 8a in 2025)
Line 3   Out-of-state (OOS) municipal obligation interest (obligations acquired after Dec. 31, 2011)
Line 4   Bonus depreciation add-back (IRC 168(k)); may be negative
Line 5   Section 179 expense over the $25,000 Indiana ceiling
Line 6a-6o  Other add-backs: name, 3-digit code, amount
Line 7   Total of lines 1-6 → Form IT-40, line 2
```
Dollar amounts are 2025 amounts; confirm against the 2026 form.

## 2026 changes
- Conformity date moves to January 1, 2026 (SEA 243).
- Wagering tax add-back is fully phased out: 0% for taxable years beginning in 2026 and later.
- New modification for qualified production property (IRC 168(n), IC 6-3-2-30). Its line or code is not yet published: code to be assigned on the 2026 form.
- The IRC 108(f)(5) student loan discharge add-back (code 150) applies only to taxable years ending before January 1, 2026 (SEA 243).
## Reporting certain prior-year modifications
A prior-year modification may have been limited by federal basis, passive loss or at-risk limits. When income later allows the modification to be realized, report it using the modification code for the year in which it actually accrued.
