# Discontinued Add-Backs: Final Catch-Up Modification (Schedule 1, Line 6)
## Description
Several add-backs arose from timing differences between federal and Indiana allowable expenses. The add-backs have been eliminated, but if you reported one, the federal and Indiana accumulated depreciation on the asset remain different until the asset is fully depreciated or disposed of. In that year, report a final catch-up modification on Schedule 1, line 6 with the original 3-digit code.
## Codes
Eliminated effective Jan. 1, 2013:
| Code | Add-back |
|---|---|
| 130 | Motorsports Entertainment Complex |
| 126 | Qualified Advance Mining Safety Equipment |
| 135 | Qualified Electric Utility Amortization |
| 121 | Qualified Environmental Remediation Costs |
| 129 | Qualified Leasehold Improvement Property |
| 108 | Qualified Restaurant Improvement Property |
| 109 | Qualified Retail Improvement Property |
| 131 | Start-Up Expenditures |

Eliminated effective Jan. 1, 2016:
| Code | Add-back |
|---|---|
| 110 | Qualified Disaster Assistance Property |
| 111 | Qualified Refinery Property |
| 112 | Qualified Film or Television Production |
## Example (2025 booklet)
Grant bought qualified restaurant property in January 2009 for $120,000. Federally he used the accelerated 15-year recovery period ($8,000 a year); Indiana required the normal 39-year period ($3,076 a year). For 2009 through 2012 he added back $4,924 a year, a total of $19,696. From 2013 the add-back ended and Indiana follows the federal deduction, so at the end of 2013 federal accumulated depreciation is $40,000 and Indiana's is $20,304. After year 15 the federal total is $120,000 and Indiana's $100,304. In the 39th year (2048), or in the year of an earlier sale, Grant reports a catch-up of -19,696 with code 108.
## Questions
- Did you report any of these codes on earlier Indiana returns?
- Was the asset sold, or has its Indiana recovery period ended, in 2026?
## Common Errors
- Reporting the catch-up with code 120 or 147 instead of the original code
- Forgetting the catch-up when the asset is sold
- Entering the catch-up as positive when Indiana depreciation lagged federal
