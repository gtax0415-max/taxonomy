# Credit for Taxes Paid to Another State
## Description
Nonrefundable credit for a New Mexico resident whose income was also taxed by another state. The credit is limited, roughly, to the lesser of each state's average rate on the doubly taxed income, and never more than the New Mexico tax. The other state's return must be attached.

## Scope
- OUT OF SCOPE for this taxonomy (team decision 2026-09-30: full-year residents with New Mexico income only)
- The credit exists only when a resident has income taxed by ANOTHER state, so it never arises on an in-scope return
- Kept so the line 20 map is complete and intake can screen these returns out

## Status for 2026
No change from the 2026 legislative session.

## Required Information
- The other state's return as filed
- Income taxed by both states

## Questions
- Did you pay income tax to any other state for 2026? (If yes, the return is outside this taxonomy.)

## Common Errors
- Preparing an in-scope return for a resident who also owes tax to another state
- Claiming the credit without attaching the other state's return

## Prompt
- I live in New Mexico but worked in Colorado part of the year.
