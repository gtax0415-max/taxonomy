# IRC Section 529A Pennsylvania ABLE Savings Account Contributions
## Description
CODE A. A deduction for contributions to a Pennsylvania ABLE account, which lets a person with a disability save without losing means-tested benefits.
## TWO separate caps, both at the gift tax exclusion
This is the structural difference from the 529 deduction, and the source of most errors. BOTH tests must be satisfied:
1. PER ACCOUNT: the maximum contributions to ANY ONE PA ABLE account BY ONE OR MORE CONTRIBUTORS cannot exceed the annual federal gift tax exclusion
2. PER CONTRIBUTOR: the maximum contributions by A CONTRIBUTOR TO ONE OR MORE ACCOUNTS cannot exceed the annual federal gift tax exclusion
So the cap binds from both directions. A parent and two grandparents each giving $19,000 to one account BREACHES TEST 1, even though none of them breaches test 2. A single donor giving $19,000 to each of three ABLE accounts BREACHES TEST 2, even though no account breaches test 1.
CONTRAST WITH THE 529 DEDUCTION at code T, which is PER BENEFICIARY PER TAXPAYER and therefore multiplies across children and across spouses. ABLE does not multiply in either direction.

## NO deduction for rollovers or beneficiary changes
- NO DEDUCTION for a ROLLOVER from one IRC 529A plan into another
- NO DEDUCTION for CHANGING BENEFICIARIES within an IRC 529A account
Only new contributions qualify.
## Note on the donation lines
PA ABLE is NOT among the ten refund-donation organization codes on PA-40 lines 32 through 36. CODE H there is the PENNSYLVANIA 529 COLLEGE AND CAREER SAVINGS PROGRAM, a different program. A refund cannot be routed to an ABLE account through the donation lines.
## The cap that can waste it
LINE 10 CANNOT EXCEED LINE 9, and on a joint return it cannot exceed what each spouse's own income would have supported separately. An ABLE contribution by a spouse with no income produces no deduction and does not carry forward.
## 2026
$19,000, both tests. Unchanged.
## Required Information
- Contributions made during the calendar year to each ABLE account
- Contributions made by OTHER PEOPLE to the same account, needed for the per-account test
- The beneficiary's name and account number
- Confirmation that amounts are new contributions, not rollovers or beneficiary changes
## Questions
- How much did you contribute to a PA ABLE account?
- Did anyone else contribute to the same account this year?
- Did you contribute to more than one ABLE account?
- Were any amounts rollovers or a beneficiary change?
## Common Errors
- Applying the 529 per-beneficiary-per-taxpayer structure to ABLE, which has neither
- Missing the PER-ACCOUNT test when several relatives contribute to one account
- Missing the PER-CONTRIBUTOR test when one donor funds several accounts
- Claiming a deduction for a rollover or beneficiary change
- Attempting to route a refund to an ABLE account through donation code H, which is the 529 program
## Prompt
- I contributed to my son's PA ABLE account.
- My parents and I both put money in the same ABLE account.
- Can I deduct ABLE contributions in Pennsylvania?
